# 启梦创作 App — 客服知识库（代码事实版，2026-09-03）

> 用途：AI 客服（看板娘数字人）的知识来源与人工客服的速查手册。

---

## 1. 产品概览、导航与页面

### 1.1 产品定位
- App 是 IdeaHub 的安卓端：React 19 + Vite 7 + Tailwind + Capacitor，形态对标抖音/TikTok 的全屏上下滑视频流，**视频由 AI 逐段生成，支持分支互动**
- 应用名「启梦」，包名 `com.ideahub.branchvideo`
- 当前版本 versionName `2.79` / versionCode `91`（2026-10-30 发版，不是强制更新；还在 2.63 及以前的请尽快更新，那几版有一个高危安全漏洞，见 §7.2；2.62 是 2026-10-08，与服务端的免费档 / 额度 / 失败退款新规则同一天上线 —— 服务器更新的时刻是北京时间 2026-10-09 清晨，知识库里说「新规则上线」都指这一刻）
- 登录页标语：「启梦 · 有想法，就是梦想启程的第一步」
- 三仓结构：server（Node+Express5+MongoDB，阿里云 ECS）/ client（官网）/ app（APK/AAB），互相只靠 HTTP 契约耦合

### 1.2 底部 Tab（共 5 格，中间是创作 ➕）

### 1.4 各页职责（页头注释）
- **FeedPage**：每屏一支，进入视口自动播放、离开暂停；带 branchTree 的互动视频在流里播开场段，点「互动 · 你来选」跳详情页做分支选择。底部进度条可以拖（2.63 起读屏软件念得出它，接了键盘也能用方向键 / Home / End 拖）。2.64 起：按住画面两侧临时 2 倍速、按住中间弹出「更多操作」（倍速 / 清屏或转屏观看 / 保存到本地 / 举报），右上角多了搜索（放大镜），细节见 §1.6
- **DiscoverPage（底栏「分区」）**：分区入口 + 搜索 + 排序，选分区不改变界面结构；2.64 起搜索框钉在页顶、有搜索历史与近期热播、分区最前面有「全部」，见 §1.8
- **WorkshopPage**（2.64 起）：创意工坊第一层 = 市场。搜索框搜的是选中的那一类（卡片 / 卡组 / 模板 / 工作流）；卡片能按卡种筛，卡片和卡组能按「最新 / 热门」排（热门只在最近分享的那一批里重排，不是全站热榜）；点卡面看详情，点「＋ 添加」收进自己的库，不花钱。「工作流」那一类是上了架的公开制作过程，按标题和作者名搜
- **WorkshopMinePage**（2.64 起）：创意工坊第二层「我的仓库」= 管理自己的卡片、卡组、模板，建组增删卡、分享卡组，以及三个造卡入口；与 `/studio`（创作现场）分工。2.63 及以前这些都在 `/workshop` 那一页上
- **StudioPage**：3D 画布 + 投影窗 + NPC 底部抽屉；工作流画布是它的一层全屏浮层
- **ProfilePage**：一套实现服务 `/me`、`/user/:id`、`/u/:author`；`/me` 多出 设置/钱包/草稿/卡片/卡组/收藏。中间那排页签是 作品 / 草稿 / 卡片 / 卡组 / 收藏（2.63 起图标下面写着名字；更早的版本只有图标）。2.64 起「草稿」那格是一支笔（锁只表示作品「仅自己可见」）、头像后面多了一条装饰底纹、别人的主页能拉黑，见 §1.9
- **CreatePage**：创作只剩两条路 — 工坊模式（3D 铸卡桌面，推演三套方案、逐段落地）与简约模式（单节点，一句话出一条短片，**不进草稿库**）
- **FlowPage**：一段的推进是三拍（写要求 → 推演三套方案 → 挑一套 → 才炼视频）
- **SimpleModePage**：三步（选起点 → 说清楚 → 确认出片），恒单段、恒直出、无方案台、不存草稿
- **CutPage（剪辑页）**：顶栏（返回 / 说明 / 导出分辨率 / 右上角主键）+ 预览 + 四个页签（剪辑 / 字幕 / 圈选 / 音频）。右上角那颗键叫「合成并去发布」：把时间轴按顺序与裁剪范围合成一条视频（手机系统的硬件编解码器做，合成本身不花 token），再进发布页；已经合成过的稿子这颗键叫「去发布」。2.62 及更早这颗键叫「下一步」。
  从工坊里某一段的「✂ 编辑」进来的单段编辑只有三个页签（剪辑 / 圈选 / 音频），右上角是「保存本段」（不合成，改好的写回那一段）。合成失败 / 取消见 §3.8
- **VideoEditorPage**：一页两模式 — 白模化前（框 5~30 秒、裁水印）与套用挂卡（角色位挂人物卡）
- **EditPage**：改标题/分类/简介/标签/封面/可见性、删除整部作品，以及「🛠 回炉重做」换成片内容（条件见 §3.2）
- **CardDetailPage / DeckDetailPage / TemplateDetailPage / TemplateMarketPage / CustomCardPage / DraftsPage / NotificationsPage**：见各文件头 1-25 行

### 1.5 启动行为
- 冷启动先装 IndexedDB 数据层（视频/账号/社交/模板/草稿/弹幕/剪辑稿），装完前显示「正在打开作品库…」
- 本机数据库读不出来时**只停住用到它的那一块**：草稿箱、剪到一半的成片、我的模板会写「这会儿没读出来」并给「重试」（进那一屏先自动重试一次），读出来之前不会往里写、不会盖掉原来的；首页、账号、发现等照常能用。只有开机连不上服务器、本机的作品库 / 账号库也读不出来时，才整页显示「作品库没能打开」+ 重试
- 系统发现本机数据库文件损坏、清空重建过时，开机会弹一次「这台设备上的本机数据被系统清空了」：只存在本机的草稿等已经没了、救不回来；已发布的作品与账号在服务器上不受影响
- 某一块画面出错时（2.63 起）**只换掉那一块**，不再整页白屏：那里显示「这一页没画出来」或「「…」这一块没画出来」，带「重载这一块」（整页出错时另有「回首页」）；重载只重画那一块，别的东西（包括工作流里的段）都还在原地。反复出现的请用户截图转人工
- 从分享链接 / 通知直接冷启动进某一页再按返回，2.63 起会退到这一页的上一级（多半是「我的」或首页），不再白屏
- 默认锁竖屏（AndroidManifest 钉着），三处例外：① 3D 工坊跟着手机转（系统开着自动旋转时）；② 首页上横屏的片子，点右侧那列最下面的「转屏」键，或者按住画面中间在「更多操作」里点「转屏观看」，会临时横过来占满屏幕，点右上角缩小键或按返回退出、离开首页都回竖屏（竖屏的片子那颗键写「全屏」，只收起按钮和文字、不转屏）；③ 工作流画布顶上那颗「⟳ 转横屏」可以手动转成横屏，再点「↩ 回竖屏」或退出画布就转回来
- 已登录但本机没有当前版本协议同意记录的用户，开屏弹补签门；「不同意」只退登录态，不拦浏览

### 1.6 首页：长按菜单、倍速、双击点赞、搜索与右侧按钮（2.64 起）
- **单击 / 双击**：单击画面暂停，再点一下接着放；双击点赞，连点两下只会点亮、不会取消（取消点赞点右侧那颗心）。2.64 起双击点赞**不再顺手把视频停住**（2.63 及以前双击完画面会停在那儿，要再点一下才接着放）；点赞爆出的红心外圈多了一圈小星星和光点，系统开了减少动画的无障碍设置时只剩那颗心
- **按住两侧 = 临时 2 倍速**（2.64 起）：按住画面左边或右边（各约屏幕宽度的 22%）约半秒，视频临时变成 2 倍速，画面上方出现「2× 快进中」，**松手就恢复**原来的速度；视频暂停着时按住两侧会先接着放。右边那一侧大部分被右侧那列按钮占着，要按在按钮以外的空白处。按住时手指一滑就算翻页，不算长按
- **按住中间 = 「更多操作」**（2.64 起）：按住画面中间约半秒，不用等松手就弹出「更多操作」抽屉（只对正在播的那一条）。里面几行
  - 「倍速」：0.75× / 1× / 1.25× / 1.5× / 2× 五档，点一档抽屉就收起
  - 「清屏观看」（收起按钮和文字）；横屏的片子这一行写「转屏观看」（横过来占满屏幕）。2.76 起全屏 / 转屏**只在这个菜单里**（右侧那列最下面换成了「做同款」碟片）；2.75 及以前右侧那列最下面是全屏 / 转屏键、与这一行同一个动作。退出点右上角那颗缩小键或按返回；已经在清屏 / 全屏里时这一行不出现
  - 「保存到本地」（旁边写「在详情页里选」）：点了只是**带你去作品详情页**，在那儿选、规矩和 §6.7 完全一样 —— 只能保存自己发布的作品；别人的作品上也看得到这一行，到详情页点保存会说「只能保存自己发布的作品。」。这一行只在装好的 App 里有
  - 「举报」：自己的作品没有这一行，离线 / 没连上服务器时也没有；没登录点了会说「登录之后才能举报。」并给「去登录」。规矩见 §6.6
  - 「不感兴趣」（**2.76 起**；服务端 2026-10-30 上线）：登录着、连着服务器、不是自己的作品时才有这一行。点了这条当场从首页消失、底部提示 6 秒内能「撤销」；之后首页 / 分区 / 搜索 / 关注流都不再给这一条，**作者主页上照样看得到**。不影响作者、不进任何计数、作者不会收到通知。2.75 及以前菜单里没有这一行
- **倍速记多久**：选的倍速对首页上每一条都生效（划到下一条照旧）；选了 1× 以外的档时，进度条上那行小字（当前 / 总时长）前面会写当前倍速（比如「1.5×」）。倍速**不保存**：离开首页（切到别的页、进作品详情页）再回来，或者重开 App，都回到 1×；作品详情页的播放器不跟这个倍速（2.71 起详情页右上角「⋯」里有它自己的倍速，见 §6.8）
- **右上角搜索**（2.64 起）：首页顶上「关注 / 推荐」右边多了一颗放大镜，点了去「分区」页、光标直接落进搜索框（第一次进分区页会先讲完那一页的引导再放进去）。2.63 及以前首页没有搜索入口，要点底栏「分区」
- **点赞 / 评论数**（2.64 起）：右侧点赞、评论下面的数字，中文界面满一万写成「万」（12,345 写成「1.2万」），一万以下照写原数；英文界面满一千就缩写（1,234 写成 1.2K，12,345 写成 12.3K）；2.63 及以前两种界面都写原数。收藏、分享下面写的是名字、不报数（收藏数从来不显示）
- **发弹幕 / 写评论时右侧按钮收起**（2.64 起）：弹幕输入条或评论抽屉开着时，右侧那一列按钮整列暂时隐藏，关掉之后再回来；2.63 及以前键盘一弹，这一列会被顶出屏幕上沿
- **收藏图标 2.76 起是五角星**（点亮金色；2.75 及以前是书签形）：首页右侧、作品页动作条、个人页「收藏」页签都一样；四角星仍表示 AI / 生成

## 2. 账号与登录

### 2.1 登录方式与注册（由服务端能力决定，前端不自行判地区）
- 可用方式来自 `GET /api/auth/capabilities`，服务端按**出口 IP** 判地区：中国大陆关掉 OAuth（Google 在墙内点了只会转圈）；短信通道没配就不报 `phoneEnabled`
- 探测失败（离线/老服务端）**退到最小集：邮箱 + 密码**
- 三种表单模式：密码登录（用户名/邮箱 + 密码）、邮箱验证码（注册/重置密码）、手机号（**登录即注册**）
- 手机号只收中国大陆号
- 密码最少 6 位
- 验证码 6 位，**10 分钟内有效**，重发冷却 60 秒
- 第三方：Google / GitHub（走系统浏览器 + 深链回来）、QQ（原生 SDK）、微信（原生 SDK）
- Google / GitHub 从浏览器回到 App 时有一道核对（2.63 起）：回来提示「忽略了…登录链接」「登录链接过期了…」、或点了取消 / 在授权页停太久 / 别的原因没登上被送回 App 的，都是没登上、不扣钱，重新点一次登录就行。**2.64 起**被送回登录页时，登录框下面有一行红字按界面语言说原因（如「Google 登录没有完成：授权被取消了，或者登录过程出了错。可以再试一次。」），登录前要去的那一页登录后接着去；2.63 及更早多半停在登录页、没有提示，偶尔一行英文「google login failed」「Invalid or expired OAuth state」之类。见 §2.10
- 注册入口：密码登录框下面有「没有账号？用邮箱注册」与「忘记密码？」两条链接（2.63 起摆在这里；更早的版本要先切到「邮箱验证码」页签才找得到注册）
- **QQ / 微信只能在 App 里用**，浏览器里点会给出真实原因「要在 App 里用（浏览器中没有 QQ/微信客户端可以拉起），先用邮箱或手机号登录」
- QQ 不在 `providers[]` 里是有意的：QQ 互联注册的是移动应用，后台没有回调地址栏
- 大陆网络下会显示「当前网络环境（中国大陆）下 Google / GitHub 不可用，已自动隐藏」
- QQ 用户没有邮箱，建号时用合成邮箱 `qq_<openid>@no-email.ideahub.local`，用户名随机 `user_<8位hex>`
- 未登录也能逛首页（登录页有「先随便逛逛」）

### 2.2 协议勾选
- 登录前必须勾选《用户协议》《隐私政策》；没勾就点登录会弹「同意并继续」确认卡
- 协议版本以「更新日期」标记，当前 `2026-08-28`。**只有更新日期变了才会要求重新同意**（登录页 / 补签门只比这个日期）：改动实质条款时才换日期；只换用词、改错别字不动日期，也就不用重新同意（2026-09-07 / 09-08 按事实改正文、2.64 把协议正文里的「合并」改叫「合成」都没动日期，见 10.4）。⚠ 别说「正文一改就要重新同意」

### 2.3 密码重置
- 登录页「忘记密码？」→ 切到「邮箱验证码 → 重置密码」；流程：`POST /api/auth/email/reset/start` 发码 → `/reset/verify` 带新密码 → 自动登录
- **手机号账号没有密码重置路径**（手机号是登录即注册；重置只有邮箱这一条） `[待确认]`

### 2.4 UID（公开数字号）
- UID = 服务端发的**随机 9 位数字**，与注册顺序/注册时间无关
- 位置：**个人页 `@用户名` 下方那一行**，点按即复制
- 用途：在搜索框里输入这串数字能直接命中这个人
- **离线账号 / 老服务端没有 UID，那一行整行不显示**
- 版本说明口径：「UID 是随机分配的数字，和注册时间无关，别人无法从中推断你的任何信息」

### 2.5 昵称 / 简介 / 头像
- 入口：设置 → 编辑资料（`/settings/profile`）
- 昵称上限 **16 字**，简介上限 **120 字**（输入框 maxLength 与落库 slice 同一个数）
- 换头像有两个入口：点「我的」页自己的头像，或「设置 → 编辑资料」点头像，打开的是同一个「选个头像」面板：前面一排 8 个官方 Q 版看板娘头像（微笑 / 认真 / 打招呼 / 大笑 / 好奇 / 欢呼 / 庆祝 / 打盹），最后一格虚线框「自定义」从相册选图（可以圆形裁切）。两种都压成 256px，远端模式转存到 Cloudinary。「编辑资料」页头像下面另有折叠的「或选一个 emoji」（12 个），「我的」页那个面板里没有 emoji
- **保存失败会回滚并明说**：「没能同步到服务器（…）——改动已撤回，联网后再试一次。」远端模式下本机不落盘，PUT 是唯一真相
- 注册时填的昵称没能存上（账号已经建好了），2.63 起会当场提示「账号建好了，昵称没存上 —— 去「我的 → 编辑资料」再填一次」：照做就行，账号本身没问题
- 改昵称的**已知历史坑**：缓存里作品的 author 是旧显示名，改名后需按 `authorId` 改写缓存；不然首页右侧头像退回字母底、点进去还是旧名字，重启才好
- `username`（登录名 / @ 句柄）**注册时定下、之后不可改**
- @ 提及：打的是 `username`，屏幕上显示的是对方**当前**的 displayName；对方改名后已发出的 @ 也跟着变

### 2.6 注销账号（SettingsDeactivatePage）
- 入口：设置页「退出登录」下方的小字链接「注销账号」，**仅远端模式显示**
- 确认方式：**原样输入用户名，严格全等**（不 trim、区分大小写），客户端不预先加工
- 页面明示后果三条
  1. 立即生效：所有设备退出登录，这个账号无法再使用
  2. 账号里的 token 余额、已购内容与已发布作品都将一并无法使用
  3. **数据不会立刻从服务器抹除**（防误操作）；恢复账号或要求彻底删除数据发邮件到 `support@ideahubs.org`
- 服务端语义：**软删除** — 只打 `deactivatedAt` + `tokenVersion += 1`（所有旧 token 立即失效），**不级联删除任何内容数据**，管理员可把 `deactivatedAt` 置回 null 恢复
- 注销后**登录也被拦**，401 整句「账号已注销……support@ 可恢复」；错误密码仍报通用凭据错误
- 离线包（本地账号）没有可注销的云端账号，页面如实解释：清 App 数据或卸载即等同注销

### 2.7 退出登录
- 远端模式：「作品、卡片和钱包都记在服务器上，重新登录同一账号就回来。」
- 离线模式：「本机的作品与数据不会被删除，重新登录即可继续。」

### 2.8 登录态三态与「我被登出了」
- `authState()` 三态 `in / out / pending`；只有 `"out"` 才把人送去登录页，`pending` 显示加载态
- 冷启动后立刻点底栏 ➕ 曾误弹登录页（2026-08-20 修）；自愈五轮退避跑完会如实退回 `out`，不会永远转圈
- 被服务端终止登录态（**目前只有封禁**）时，登录页开屏会显示原因（`consumeAuthNotice`）
- 「**登录状态过期了，重新登录之后再试**」「登录已过期，请重新登录…」是另一回事：已经登录着，但服务器那边的登录凭据失效了（举报、拉黑这类操作时会这么说）—— 退出再登录就好，不扣钱。**别和 §2.10 的「登录链接过期了（超过 15 分钟）」混为一谈**：那一句只出现在 Google / GitHub 登录的半路上

### 2.9 封禁 / 黑名单 / 私信
- **App 里没有私信、好友申请功能**（属于官网产品线）
- **拉黑有**（2.46 起）：作品详情页（2.71 起在右上角「⋯」打开的「更多操作」最下面一行；2.70 及以前在正文「举报」旁边）、评论里对方那一条上（「⋯」后面），都有「拉黑」；**2.64 起别人的主页上也有**（「关注」「分享主页」下面那一行小字；2.63 及以前主页上没有）。点了先弹「拉黑「…」？」，写明后果：他的作品、评论、弹幕都不会再出现在你这儿；他也看不见你的（**双向**）；他不知道自己被拉黑了，谁都不会收到通知；**这不是举报**，想让平台处理要另点「举报」（主页上只有拉黑、没有举报：举报针对作品 / 评论 / 弹幕（2.71 起的版本还有人格市场里的人格），见 §6.6）。成功后提示「已拉黑「…」——你们不会再看见彼此的内容。」，键变成灰的「已拉黑」，首页当场拿掉他的作品；没成功会在弹层里说原因、不关窗，再点一次就行
- 拉黑键只在连着服务器时出现（离线模式没有）；自己的主页、作品和评论上没有；没登录点了会说「登录之后才能拉黑。」并给「去登录」（登完回到这一页）；用老式按名字打开的主页链接（`/u/名字`）进来、App 认不出是谁时，主页上不显示这颗键
- 名单在「设置 → 已拉黑的人」，可以随时解除（拉黑跟着账号走，换设备还在）
- 封禁由管理后台执行：「封禁挡的是**登录与一切带登录态的请求**，对方会看到下面这句原因」
- 管理员行不渲染封禁/删除（防手滑），服务端也会拒

### 2.10 Google / GitHub 登录没登上（登录链接被忽略 / 过期）
- 2.63 起，点 Google / GitHub 登录时，App 先在这台手机上记下「刚发起了一次登录」（一次性的，只认最后点的那一次，15 分钟内有效），从浏览器回到 App 时只收对得上的那一条。防的是别的 App 或网页往手机里投一条登录链接、把你登成别人。QQ / 微信走原生 SDK，不经过这一道
- 轻提示「**忽略了一条不是本机发起的登录链接**」：回来的这一条对不上这台手机刚发起的那一次。常见情况：登录页上点了不止一次（只认最后点的那一个页面）、同一次登录的回程又来了一条内容不同的（一次登录只认一次；一模一样的那一条再打开一次，App 直接不理、什么都不说）、或者这条链接不是这台手机这次登录发起的（别处发来的）。
  这一条**没有登录、没有换人、不扣任何钱**，只是 App 挡下了一条对不上的回程；回到 App 登录页重新点一次 Google / GitHub 登录，在打开的那一个页面里走完就行
- 轻提示「**登录链接过期了（超过 15 分钟），请重新登录**」：是这台手机发起的，但从点登录到真正回到 App 隔了 15 分钟以上。同样没登上、不扣钱；回登录页重新点一次登录，一口气走完
- 在 Google / GitHub 的页面上点了「取消」（或者 Google / GitHub 那边报了错），2026-10-20 起会**自动回到 App**、浏览器那一页自己关掉：这一次没登上、不扣钱，重新点一次登录即可；也可以改用邮箱 / 手机号登录。**2.64 起**回到登录页时，登录框下面（协议勾选那一行上面）有一行红字：「Google 登录没有完成：授权被取消了，或者登录过程出了错。可以再试一次。」（GitHub 登录的写 GitHub；英文界面是对应的英文）。**2.63 和更早的版本**回到 App 时多半就停在登录页、**什么提示都没有**；偶尔（比如在浏览器里待着的时候 App 被系统关掉过）会显示一行英文「google login failed」或「github login failed」，意思都是这一次没登上，照样重新点登录
- 在授权页上停得太久：从点登录算起超过 15 分钟才回来的，App 只弹上面那句「登录链接过期了（超过 15 分钟）」；10 到 15 分钟之间才点同意的，服务器那边那一次登录已经过期（10 分钟），同样会回到 App、没登上 —— **2.64 起**登录框下面写「在授权页上停留太久，这次登录已经失效了，请重新登录。」，2.63 及更早多半没有提示、偶尔显示一行英文「Invalid or expired OAuth state」。两种都是重新点一次登录、一口气走完。10-20 之前，取消或停太久都会停在浏览器里、要自己关掉那一页再回 App
- 别的原因没登上（**2.64 起**也是登录框下面一行红字，按界面语言说）：「这个 Google 账号的邮箱已经用别的方式注册过了：请用当初注册时的方式登录。」—— 这个邮箱在启梦早就有账号（比如当初用邮箱 + 密码注册的），用当初那种方式登录，忘了密码点「忘记密码？」；「Google 没有提供邮箱地址，没法用它登录。」—— 改用别的方式登录；「没拿到 Google 的账号信息，请再试一次。」「Google 登录时出了错，请再试一次。」—— 再点一次，反复出现就转人工。GitHub 登录的提示里写的是 GitHub；认不出的原因照原样显示。⚠ **2.63 及更早**遇到这几种时多半也停在登录页、什么都不说（偶尔显示服务器的英文原句，如「Google email is already linked to another IdeaHub login method…」）：用户说「点了 Google / GitHub 登录、没点取消，回来就是登不进去、什么提示都没有」时，常见原因之一就是这个邮箱已经用别的方式注册过（也可能是在授权页停太久）—— 请他用当初注册的方式登录，或者更新到最新版看具体原因
- 登录完回到哪：**2.64 起**，从哪一页被请去登录（比如没登录时点了底栏 ➕、「我的仓库」、举报 / 拉黑），用 Google / GitHub 登录成功后就回到那一页；没登上之后改用密码 / 验证码登录，也一样接着去那一页。2.63 及更早用 Google / GitHub 登录成功后一律回首页；在浏览器那段时间 App 被系统关掉过的（回来是重新打开），2.64 也回首页
- 反复回不来、或者上面这些提示之外的报错，转人工时请用户说清用的是 Google 还是 GitHub、在哪一步停住、登录框下面那行红字的原文（或截图）

## 3. 创作流程、草稿与限制

### 3.1 流程
- 底栏 ➕ → `/create` 岔路口 → **工坊模式（`/studio`）** 或 **简约模式（`/simple`）**
- 一段的推进是三拍：写要求 → 推演三套方案（2.78 起剧情直接写成 2~3 个镜头、各带开头画面预览；承接上一段时不画）→ 挑定一套（可换帧、改剧情、按修改重画）→ 才炼视频
- **必须炼出本段视频才能开下一段**（段间靠上一段的真实尾帧承接起拍）
- 出片完成 → 「完成视频」（组稿）→ 剪辑页 `/cut` → 右上角「合成并去发布」（把时间轴合成一条视频，合成不花 token）→ 发布页 `/publish`；2.62 及更早那颗键叫「下一步」。合成失败 / 取消见 §3.8
- 工坊与工作流是**同一条流水线的两个面**，换个模式打开不会要求重炼、不会重复收费
- 生成期间**可以离开工作流页去逛**（站内切页不会中断），结束时会有全局悬浮胶囊叫你回来；2.63 起点它回到开炉的那一面（3D 工坊、简约页或工作流画布）

### 3.2 草稿
- 草稿 = **还没发布的半成品**，存在**这台设备的 IndexedDB**（`data/drafts.ts`），**按账号分开**（同一台手机换账号只看得到当前账号自己的草稿；升级前的老草稿归升级后第一个登录的账号）；`/drafts` 不设登录墙，但**没登录时草稿箱是空的** —— 登录回原来的账号就能看到
- 草稿索引与正文分开存（正文带 1MB 级的帧）
- **草稿上限 20 条**（按账号各算），超过从最旧的开始清（按 updatedAt）；2.63 起清掉的那一刻会提示「草稿满 20 条，最旧的「…」已清掉」（只是告诉你，**没有撤销**，清掉的找不回来；更早的版本一声不响）
- **删草稿与撤销**（2.63 起；在「我的」页「草稿」页签或草稿箱里点开一条 →「删除」）：**没出过片的草稿一点就删**，屏幕下方出轻提示「已删掉「…」」带「撤销」，6 秒内点它就原样放回来；
  **带已出片段的草稿仍会先问一句**（「里面有 N 段已经花钱炼出来的成片，这条草稿是它们唯一的备份……」），点「确认删除」之后同样给 6 秒「撤销」。问「草稿删错了能撤回 / 恢复吗」：6 秒内点「撤销」能，过了就找不回来了（草稿只在本机，没有回收站）；撤销没成会说「没能恢复这条草稿」。2.62 及更早每一条删之前都先问一句、没有撤销
- 草稿标题重命名上限 40 字
- **简约模式不进草稿库**（只有一段、写一句话就出片、直通发布）
- 自动存盘：每炼出一段自动存草稿（`hooks/useFlowActions`，工坊与工作流共用）
- **卸载 / 换设备 = 草稿全丢**（草稿只在本机 IndexedDB，从不上传）
- 已发布作品**可以「🛠 回炉重做」换内容**（2026-09-07 上线）：编辑页把发布时留存的工坊工程取回工坊接着改，再替换原作品——**链接不变**，播放/点赞/评论都保留，作品会标注版次（详情页「N 月 N 日重新剪辑过 · 第 N 版」），收藏过它的人会收到通知，**原有弹幕会被清空且无法恢复**（弹幕按全片时间轴打，换内容必然对不上画面）
- 回炉的四种**做不了**：这条作品没有留存工坊工程（2026-09-07 之前发的都没有，想换内容只能重新发一条）／作品设为按分集收费／作品被平台下架期间／作品还在上传。另有一档由服务端拒绝：「这条作品暂时不能改内容，请稍后再试。」
- 工坊工程存在**服务器**上（不是本机草稿），所以换设备、清缓存都还在；上限**每人 100 条 / 单份 2MB / 合计 50MB**，满了要到较早那些作品的编辑页删掉几条再留存（服务端回 `PROJECT_QUOTA`）。⚠ 这三个阈值是**拍的、不是量的**（服务端 schema 自己这么写：100 条 × 典型 80KB ≈ 8MB，50MB 是天花板不是预期值），上线后会按真实分位数调，别把具体数字当成承诺
- 留存的画布**只含永久地址**，所以有些预览图留不下来（回炉打开时会用虚线框标出「这一格的预览图没有留存」，重新推演可以补回来）

### 3.3 换流水线 / 丢段的守卫
- 「整表换掉 nodes」的七条入口都要先问 `flowDirty`，弹 `DiscardFlowDialog` 说清哪些其实存住了
- **在途生成时一律不许换/不许删段**：出片是几分钟的异步、没有 AbortController，换掉后回包时钱照扣、写回落空
- 「有一段正在生成中，等它跑完再换走向」
- 「这一段已经出片：换模板会作废这段成片。想换就删除本段重加，或先接受重炼这一段的花费」
- 删掉一段之后能不能撤销，见 §3.6

### 3.4 时长与数量限制
- 视频段时长**按档位**（`VideoTier.minSec` / `maxSec`，App 2.62 起放开；服务端 2026-10-03 就已放开）：极速、标准 **3~10 秒**；草稿、高清 **4~15 秒**；电影级 **4~30 秒**；真人档只有 6s/10s 两档；越长越贵
  （**2.61 及更早的包各档最长都只能选 10 秒**，要更长的请更新到最新版（2.62 起就放开了，现在最新是 2.71）；2.55 及更早的包在高清档还让选 3 秒，选了会失败、不扣出片钱；2.61 及更早的包没有「草稿」）
- 白模模板：输入窗口 [5,30]s，模板视频窗口 [4,30]s（两个数不是一回事）
- 服务端 publish schema：segments 1~60 段、标题 1~120 字、简介 ≤4000 字、分类 ≤40 字、tags ≤20 个 × ≤40 字、卡组 ≤60 张
- 作品话题标签（App 侧产品口径，故意小于服务端）：**最多 6 个，每个 ≤10 字**
- 卡名 ≤120 字、卡简介 ≤2000 字（**服务端超了是整发 400，不是截断**）
- 分享推荐语 ≤200 字
- 图位花名 ≤24 字
- 出片提示词（这一段发给视频模型的画面 / 剧情文字）上限按档位（2.62 起）：草稿 / 高清 / 电影级 500 字（方舟官方建议的上限），极速 / 标准 / 真人档 400 字；套白模模板的段不论哪一档都是 400 字（2.61 及更早所有档都是 400）。分镜表、自定义、参考图直出这些写提示词的框跟着这一段选的档位封顶，换档后上限跟着变。挂的卡带进去的设定和点名句也算在这个上限里，正文写满时末尾可能有几十个字发不出去（出片进度里会提示），写短一点或少挂一张卡就好
- 一次铸卡最多出几张卡：卡组 `DECK_MAX_CARDS = 8`、模板 `TEMPLATE_MAX_CARDS = 6`
- 一个卡组最多 2 个 3D 模型（`DECK_MAX_3D = 2`）
- 一张卡最多 2 张图进出片管线（第 3 张画了也用不上，档位 `views` 不许写 3）
- 参考图协议上限：2.0 系列 1–9 张，2.5 系列 1–30 张

### 3.5 上传队列（发布失败的成片）
- 发布失败的作品进「待上传队列」，每条**记着主人**，只发自己的（换账号后别人那条原样留着）
- 队列项是那条付费成片在磁盘上的**唯一指针**，删了就再也传不上去

### 3.6 删掉一段与撤销（工作流画布、工坊）
- 「🗑 删除本段」在画布上点开一段的编辑窗、工坊投影窗里都有。**还没花过钱的段一点就删**；**出过片或推演过三套方案的段**（花过 token 的）要在 3 秒内再点一下才删（键会变成「真的删？这段成片会没」或「真的删？推演出的方案会没（花过的 token 不退）」）
- 2.63 起删掉之后屏幕下方出一条轻提示「已删掉第 N 段」，带「撤销」键：**6 秒内点它，这一段原样放回原来的位置**（写好的要求、分镜、挂的卡、出好的成片都在），不花钱。用户问「删错了一段能撤回 / 恢复 / 找回吗」就是这个：6 秒内点「撤销」能；过了 6 秒提示收起，App 里就没有别的入口放回来了，出过片的段只能重新出片（再花一次钱）。2.62 及更早没有撤销
- 只记得**最近删的那一段**：6 秒内又删了另一段，前一条提示被新的这条顶掉，先删的那一段就撤不回了（只有最近删的那一段能撤销）
- 「撤销」也可能放不回去，会当场说原因：有一段正在生成中（「等它跑完再恢复」，免得那一炉的成片写到别的段上）；流水线整个换过了（打开别的草稿、做同款、套模板，「没有可以恢复的段」）；白模复刻段只能是最后一段、只能有一段，放不回原位
- 有一段在生成中时删不了段（见 §3.3）

### 3.7 工作流画布：放大 / 缩小 / 拖动看全
- 画布右上角有一列三颗键（2.63 起）：**＋ 放大**、**1:1 恢复原大小**、**－ 缩小**。每按一下放大或缩小 1.25 倍，以屏幕中心为准；范围 0.4 倍 ~ 2 倍
- 也可以双指捏合缩放、单指拖动画布（电脑上用鼠标滚轮缩放）。画布太小看不清、段卡挤在一起：点 ＋ 放大，或点 1:1 回到原大小；找不到某一段就缩小看全再拖过去。2.62 及更早没有这三颗键，只能捏合 / 滚轮
- 「＋ 加一段」此刻加不了时（2.63 起），那颗键上直接写原因，不用点了才知道：「先把这一段炼出来，再铸下一段」（上一段还没出片，见 §3.1）或「白模复刻段只有一段：画面与运镜整个来自模板视频，没有可续的下一段」

### 3.8 剪辑页合成：报错 / 取消 / 回去改（「合成并去发布」）
- 合成是在**手机上**用系统硬件编解码器把时间轴拼成一条 mp4，**合成本身不花 token**，合成失败、取消、重新合几次都不扣钱（会花钱的只有重新出片、圈选重拍这些）。2.62 及更早的界面把这一步叫「合并」，主键叫「下一步」；2.63 里还有几句提示写着「合并」（如「回到合并之前接着剪」），2.64 起剪辑页统一叫「合成」（只剩「已经有一炉在合并了…」这一句还写着合并），说的都是同一步
- 合成中可以切到别的页面或别的 App（「合成走系统硬件编解码，不再录屏——可以切走，只是系统可能把它拖慢」）；合好时人不在剪辑页，会在胶囊 / 通知里说「成片合好了，去发布吧」，点它去发布页，不会把人突然拽过去
- 老稿子里还是临时链接的段，合成前会先转存成永久地址（「第 N 段成片转存中（换成永久地址）· 已等 N 秒…」），一段最多等 2 分钟，等不到也照样往下合
- 「**合成失败：第 N 段的视频取不到了（HTTP 403）……临时链接只活 24 小时……**」：这几段当初没能转存成永久地址，方舟的临时链接过了 24 小时就拉不到了，**这条片子现在合不了**。出路只有两条：回「我的 → 草稿」打开草稿把这几段重新出片（会再花一次钱），或者在剪辑页删掉这几段再合。清缓存、重装都没用
- 「第 N 段还没有视频（只有设定帧），合成做不了」：先回工作流把这一段炼出来；「第 N 段还不是永久地址，合成用不了」：回「我的 → 草稿」打开草稿，等它转存完再来
- 「已取消合成。片段、圈选和配乐都还在，随时可以重新开始。」：点了「取消合成」，什么都没丢，再点「合成并去发布」就行
- 「已经有一炉在合并了，等它跑完就会带你去发布页」：上一次合成还在跑（不是失败），等它跑完；别再点一次
- 「这台设备上合成用不了……请在手机 App 里完成合成」：只在浏览器里出现，合成只有安装包里能做
- 「合成失败：」后面跟着一串英文（Asset loader error 之类）的：先确认网络通、再合一次；还不行就把导出分辨率降到 720P、或删掉可疑的那一段再试；仍然失败请截图转人工，说清是第几段、用的哪个档位
- 合成成功但带着提醒的（话会跟到发布页上）：「这条成片没有声音……」（素材本身无声、也没加配乐 —— 回剪辑页「音频」加一条再合）；「选的那条音轨本身没有声音（多半是白模模板的原片……）——这一条按无声合成了」；「配乐用的是自动预置的原片音轨，而你裁过 / 删过 / 换过片段顺序……会和画面对不上」；「这条成片有 N MB，接近服务器上限（约 100MB），可能传不上去」（删几段或降一档导出分辨率再合）；字幕 / 配音排不上、配音是改字之前那一版的，也会各说一句。这些都是成片已经合好了，改不改由用户定，再合一次不花钱
- 合好之后想再改：剪辑页「↩ 回去改」或发布页「↩ 回剪辑页改一改」，回到合成之前的时间轴接着剪，改完再合一次（不花钱）。2.56 之前（2026-09-30 之前）合的老成片没有留下合成前的片段，回不去，只能直接发布或回「我的 → 草稿」重做一条（简约模式没有草稿，只能重新创作）

### 3.9 做模板的入口卡（模板货架顶上，2.64 起）
- 在哪：模板货架最上面 —— 创意工坊（底栏「工坊」）选「模板」那一类、「我的仓库」的「模板」页签、「视频模板」页（`/templates`）的「模板市场」和「我的模板」两个页签；「工作流」页签里没有
- 两种样子，点哪个都一样：「我的模板」里还一个都没有时，是一张带看板娘插画的大卡，标题「创建属于你的视频模板」，写着三步（2.71 起「① 传视频 / 写提示词 › ② 做成模板 › ③ 套用出片」，白模路开不了时是「① 写提示词 › ② 选封面 › ③ 套用出片」；2.64 ~ 2.70 是「① 传视频 › ② AI 换成白模 › ③ 发布到市场」）和「开始创建」键；做过模板之后缩成一行小条「再做一个视频模板」+「开始」。2.63 及以前没有这张卡：入口是「我的模板」页签里一行虚线字「传一段视频做白模模板（自己做好的白模片也行）」，点开之后是同一个窗口
- 点了打开做模板的窗口，第一屏挑两条路：「让 AI 把里面的人换成白模人偶」（任意视频都行，这是一次真实的电影级出片，价钱在下一步框选时整句报出来）；「它本来就是白模 / 人偶片，直接用」（只认人、不出片，屏上写「约 2.8k」：2,800 token 是上限、实收只少不多；超过 30 秒的素材整条切段登记，每段各认一次、按段算）。**这两条传视频的路都花 token**，都在按下开始之前报价、确认了才扣；入口卡上不写具体数。2.71 起第一屏最下面多一条「没有视频？只用文字 + 封面」（做模板本身不花 token，见 §3.10）
- **没付过钱的账号（免费版）现在做不了白模模板**（2.71 起的文字模板不受这一条限制）：两条白模路都只走「电影级」（会员档），窗口里用红字说「白模那两条路都只走这一档，所以现在还开不了 —— 开通会员套餐（或充值过任意一笔）就能用……」，选视频的键点不动、一分钱不扣。⚠ **2.74 及更早**的那一屏底下有时还会多一句「改选「经典配方」仍然可以做模板」，那是**过时的话**：「经典配方」那条路 2.61 起就收掉了，屏上找不到，别照着它给用户指路 —— 2.71 ~ 2.74 上想做模板的免费用户，请他回到第一屏选最下面的「只用文字 + 封面」（§3.10）。2.75 起这句删掉了，红字下面改成一行能点的「不传视频也能做模板：改用「只用文字 + 封面」，不用会员，做模板也不花 token」，点了直接打开文字模板那一屏（所在地区用不了白模那一档时红字下面也有这一行，只是不提会员）
- 没登录也看得到这张卡（逛市场不用登录），点了先去登录页，登完回到原来这一页；刚打开 App、还在确认登录状态时点，会提示「正在确认登录状态，稍等一下再点」。离线、这次没连上服务器、或服务器不支持白模模板时：2.70 及以前整张卡不显示；2.71 起卡照样摆，点了直接进「只用文字 + 封面」那一屏
- 做好的模板进「我的模板」，**不会自动上市场**：要到模板详情页里先逐个核对角色位、再用它真出一段片，发布键在那之前写「发布（需先试炼）」，过了才变成「发布到模板市场」
- AI 换白模那一发没等到结果（关了 App、断网等），货架上会摆「还没取回」的卡片，取回不再花钱；2.64 起在创意工坊市场那一层取回成功，会自动跳到「我的仓库」的模板页签
- 别人套用你的**视频模板（白模模板）**出片**不算**你作品的同款，拿不到同款奖励。上架的「工作流模板」（公开的制作过程）是另一回事：别人在你的作品上点「做同款」，或在制作过程 / 工作流模板页点「按这个流程做同款」整条照做、再公开发布的，才算同款、才可能有同款奖励（用「接在我现在的流水线后面」接进去的不算；条件和数额以发布页那句为准）。规则见 §9.3 的 v2.61，到账通知见 §6.5
- **模板作者奖励**（2.77 起；服务端 2026-10-30 已上线；服务器也要先更新）：别人套用你登记在服务器上的视频模板出了片、**公开发布**满一段时间还公开着，**平台**奖励**模板作者** token（不是套用的人付的，套用不多花一分钱）。每次多少、每天最多几次、每个模板一共最多几次、要挂多久**全由服务器下发**，写在模板详情页「发布到模板市场」那一行下面与「我的模板」页签头上那一句里 —— **规则以 App 里那一句为准**，客服不替它报数。自己套自己的模板不算；两人之间有拉黑不发；作品满期那一刻已私密 / 下架不发、之后再改回公开也不补；到了上限的不顺延；只用文字 + 封面做的文字模板（只存本机、没登记服务器）不在此列。老版本 App 发布的作品不带「套用过哪个模板」，发不出这笔奖励。到账时消息页一条「有人套用了你的模板《X》出片」+ 金额，点进去落到自己的模板详情页
- **白模模板记下神态（2.71 起）**：AI 白模化时顺带记下每个人的神态，核对角色位面板上显示「神态：…」；套用时按卡名往提示词里加一句，不多收钱。只有服务器更新之后**新白模化**、角色位不超过 3 个的模板才有（同一张卡挂两个位子的不写）；老模板和「本来就是白模片」那条路做的没有。**不保证**表情一定出来：试验里二次元素材补回了惊讶 / 大笑，半写实素材加不加差不多

### 3.10 文字模板（2.71 起）
- **文字模板（只用文字 + 封面，2.71 起）**：写提示词（屏上提醒【】标题、引号、时间轴等写法，可一键改）→ 给正文里的「图1~图4」起名（最多 4 个，套用的人按名字补图）→ 时长、画幅、默认档（每档能不能跑、套用一次多少钱都写出来；按秒写的时间轴只有电影级照着跑，别的档要改成「镜头1、镜头2…」）→ 选封面、起名。**做模板不花 token**；**要登录才能存**；**只存在这台手机上**（按账号分开），**还不能发布到市场**（屏上写「要等下一版」）
  - 套用：详情页「用这个模板出片」（键上带价）→ 落成一段参考图直出段，顶上横幅写出处和出片前还差什么（缺图、正文太长、时长短于时间轴、这档跑不了；没补齐点生成会被拦下、不扣钱）；在参考清单里按名字补图，「摘掉模板出处」可改回普通段。出片按档计费；一个图位都没有的会先补画 1 张开头画面（按张算，已含在报价里）

## 4. AI 生成与费用

### 4.1 供应商与模型
- 主供应商：**火山引擎方舟（Ark v3）** — Seedream 生图 / Seedance 生视频 / 豆包对话
- 真人档换供应商：**MiniMax 海螺 2.3-Fast（768P，只做图生视频）**；2026-09-26 起走 MiniMax **国际站** `api.minimax.io`（此前是中国站）——**不许再说「境内、照片不出境」**
- **同一档两家可选（2.71 起）**：服务器同时给得出 Seedance 和 MiniMax（海螺 H3）时（现在境内外都是；海外开启地区限制之后只剩 MiniMax），档位那一排上面有「出片模型来自 Seedance / MiniMax」开关（本段设置、选法屏、工坊铸段窗都有），草稿 / 高清 / 电影级各有两家的对标。默认 Seedance，选过的记在这台手机上、按账号分开。境内第一次选 MiniMax 会先确认：这一段的文字描述和参考图（包括人物卡照片）交给 MiniMax 在境外的服务器处理。换家就是换成另一家的那一档，价钱和能做的事按那一家算（芯片上写着价）；这一段换不过去时（比如白模模板段、文字模板没写那一家），开关下面会说原因
- TTS 走火山 openspeech（另一条产品线，另配 `TTS_APPID`/`TTS_TOKEN`）；**方舟没有 TTS**
- 密钥永远在服务端，不进 App 包

- 默认档：付过钱的人是「标准」（停用后「高清」），没付过钱的人是「极速」（停用后「草稿」）
- 真人档只有 6s / 10s 两个整档（海螺 768P 的全部合法时长），按发一口价 **85,000 / 143,200 token**（2.53 起）。2.52 及更早的包报价写 135,000 / 270,000，服务端按 125,300 / 250,600 实扣——老包用户问「扣的比报的少」就是这个
- 真人档**没有「推演三套方案」这一步**（按发直出）；提示句见 `deriveIssue`
- **除真人档外，其余各档（极速 / 草稿 / 标准 / 高清 / 电影级）全部拒收真人照片**（方舟两套探测器：名人按版权拦、普通人按隐私拦，整发拒收）
- 真人卡的合规出路：在卡上勾选**「火山引擎适用」**（点了会跳到火山引擎登录并扫脸认证，认证成功回到 App 自动勾上；卡片详情页也能勾/取消）。勾上之后草稿 / 高清 / 电影级三档（Seedance 2.0 / 2.5 系列；「草稿」是 2.62 起多出来的，免费用户能用的就是它）才对这张卡开放（出片发的是方舟可信素材 `asset://`，不发照片）——但**只在「简约模式」不带首帧直接出片时可用**：工作流推演出的画面、接着上一段拍的画面、自己传的首帧里有真人脸，会被供应商整发拒（2026-09-30 实测），这些情况下这几档是灰的（2.54 及更早的包还不会变灰、点了会失败）；没勾的真人卡只有「真人」档可点（会员档），其余档位是灰的
  - 2.54 之前的包：造卡入口叫「真人素材扫脸认证」，卡片详情页是「方舟可信素材」窄条（发起授权 / 填素材 ID），档位不会预先变灰、点生成才被拒

### 4.2b 按模型适配

### 4.3b 九宫格分镜 / 对话正反打：画面每张 13,733 token（含 AI 看一遍）、过肩多画人
- 这两种「跟着做」做法的画面都用默认出图档「速写」画，**每张 13,733 token = 一张图 13,333 + 画完自动让 AI 看一遍 400**（App 里印成「13.7k」）。选法屏上这两行写着「写分镜 400，画面每格 13.7k（含 AI 看一遍）……」「写对白 400，三个机位每张 13.7k（含 AI 看一遍）……」
- **九宫格分镜每格从 2.62 起就会看一遍；对话正反打的三个机位从 2.64 起才看**。2.63 及以前的对话正反打不看，每个机位只收一张图 13,333（那颗键印「最多 40.0k」）。2.64 起按钮是「🎥 画三个机位（最多 41.2k）」「🖌 重画这一张（13.7k）」
- **什么时候扣**：对话正反打的每个机位（以及九宫格里单独画 / 重画的那一格）是一张一张画的：每画一张，服务器在发出出图请求时先扣一张图的钱（13.3k），画的那半分钟左右打开钱包就能看到少了；上游明确拒绝的（敏感词 400、限流、5xx 等）当场原样退回。九宫格一次画一组时不一样：受理那一刻按要的张数一起预扣（每张 13.3k，九张约 12 万），一组要画几分钟，结束时按实际拿到手的张数结算 —— 拿到了几张的，多扣的退进套餐额度（plan）；一张都没拿到的全退、按原来扣的两桶原样退回（见 §4.5）。每张画好之后自动让 AI 看一遍，看图那 400 也是发出时扣，用户不用点、也关不掉。对话正反打：双人镜头没画成就停下，两个过肩不画、不收钱；**没画成的那一张不看，也不收看图的钱**；它的图钱分三种：上游明确拒绝的不扣（已退回）；图其实画出来了、App 却没取回来 / 读不出来的照扣，屏幕上写「这一步已计费 13.3k token。」；没等到回包（超时、断网）的写「这一步可能已经扣了 13.3k token——以「我的」页的 token 余额为准。」。余额要够「最多 41.2k」才能画三个机位，够 13.7k 才能重画一张
- **AI 看出问题时**：那一张右上角标一个 ⚠，点开写原因，例如「画面里有 3 个人（这一张应该是 2 个）」「同一个人出现了两次」「画成了 2 格拼图」。**看出问题只做标记：不会自动重画，不拦着往下走（第④步照样能落段出片），也不退这张图和看图的钱**；要重画得用户自己点「🖌 重画这一张」，再收一张 13,733。AI 也会看漏、也可能误报，没标 ⚠ 的也建议自己看一眼
- **「这一张 / 这一格没核对上（AI 没看成）」**：图照样留着，图钱照扣。看图那 400：AI 回了话、只是读不懂的照扣；没等到回话的会跟一句「这一步可能已经扣了 400 token——以「我的」页的 token 余额为准。」；上游明确拒绝的不扣。不会自动再看一遍，只有重画那一张时才再看
- **过肩多画一个人**：2.64 起过肩照着双人镜头画时「只沿用地方、光线与两人的衣服，站位按这个机位重新摆」，同一个人在前景露肩膀、又在中景整个站一遍的情况少了很多，但**没有根除**，所以才加了 AI 看一遍。别说「不会再多画人」
- 对白落成几段之后，三个机位还留着：接着在同一个地方往下说，不用再画、不再花钱。**换人或改整体交代之后，三个机位都会标成「过期了」**；单独重画双人镜头之后，两个过肩也会标成过期（它们是照着双人镜头画的）。**只要有一句对白用着过期的机位，第④步的出片键和「只铺成…」都是灰的**，提示「「…」过期了（人、整体交代或双人镜头改过）—— 回上一步重画一下。」。要接着落段有三条路：① 把人 / 整体交代原样改回去，机位就不再过期，不花钱；② 重画用到的那几张，每张 13.7k，或者点「🔄 三个一起重画」（最多 41.2k）。过肩是照着现在那张双人镜头画的，所以人或整体交代改过、双人镜头也要用时，先重画双人镜头再画过肩（反过来的话双人镜头一重画，刚画好的过肩又过期，那几张白花了）；双人镜头没有一句用到时，只重画用到的过肩也能落段；③ 只有双人镜头重画过、两个过肩过期时，可以把那几句换到双人镜头上。没有一句用到的过期机位可以不管。**画幅在画第一个机位之前选，画好任何一张之后画幅那排键就是灰的、向导里换不了**：「🔄 三个一起重画」画出来还是原来的画幅（2.74 及以前屏幕上写着「要换画幅得三个一起重画」，这条路不存在；2.75 起改成了「画好之后画幅就定了，「三个一起重画」也还是这个画幅」），别让用户为了换画幅去花这最多 41.2k。这个向导只存在 App 运行期间：把 App 彻底关掉（从最近任务里划掉）再打开，人、对白、三个机位都会清空，这时才能重新选画幅，机位要重画（最多 41.2k）；拿不准就转人工反馈。这和 AI 看出问题标的 ⚠ 不是一回事：⚠ 不拦第④步，「过期了」拦。别跟用户说「要不要重画由你定」

  - **每一次云端语音合成都按字符扣 token**：每个字符 33（标点、空格、英文字母都算），一句 40 个字符约 1,320。会合成语音的地方：AI 客服 / 数字人念回复、在客服页点一下看板娘时她回的那一句（中文界面一句 6~18 个字，约 200~600；**2.71 起的版本**在英文界面念英文，一句 20~47 个字符，约 660~1,550，2.70 及以前英文界面也念中文。**2.71 起的版本**同一句在本次打开客服页期间只合成一次、只扣一次，再点到同一句不再扣（还没念出来就点了发送 / 停止也只扣这一次；网络断了没拿到声音的那一次例外，再点到会重新合成、再扣）；离开客服页再进来、或在声音面板换了声音之后，第一次点到会重新合成、照扣一次。2.70 及以前每点一次都重新合成、扣一次）、老师开口说话、工坊里铸卡师说话、设置页点音色试听（试听句 26 个字符，约 858）、客服页声音面板里的试听 / 混音试听、剪辑页配音（含一键成片默认勾着的「用完就配音」、在「💬 说一句」里让它配音（比如面板上那句「全部配音」）；**只算看不见「配音免费，每个账号每天 1000 字」那行小字的版本**，即 2.62 及以前 —— 2.63 起见下一条）。
    客服页、上课页右上角的 🔊 和工坊铸卡师对话框里的声音键是**同一个开关**，默认开着；关掉之后客服 / 数字人、老师、铸卡师自动说的话不再念、不再扣（铸卡师会变成嘴动没声音）；**试听、配音是自己点的，不受这个开关管**：试听点一次扣一次；老版本的剪辑页配音按句扣（一次给几段配音就扣几句，一句念不完自动提速重合成的那一次另扣）；云端语音没出声（上游没给音频）的那一次自动退回
  - **剪辑页配音（含一键成片的「用完就配音」）新版免费、每天限量**：服务器更新之后认新版剪辑页带的标记 —— 带标记的配音**不扣 token、不算进每日上限**，每个账号每天最多 1,000 个字符（标点、空格、英文字母都算；念不完自动提速重配的那一遍也算），用完当天就配不了、UTC 0 点（北京时间早上 8 点）重置，不会转成扣 token。**怎么分新旧**：新版剪辑页「🔊 给 N 句配音」按钮下面那行小字写着「配音免费，每个账号每天 1000 字」（英文界面是「Voiceover is free, up to 1000 characters per account per day…」）—— 这行字只在服务器真的支持时才出现，**看得见它的才免费**；看不见的多半是 2.62 及以前（按钮上虽然也写着「现在免费」），照上一条按句扣；带这行字的是 2.63 及以后的版本（2.63 是 2026-10-15 发版，现在最新是 2.71），更新到 2.63 或更新的版本之后就免费。新版偶尔取不到音色目录时这行字也不出来，但照样是免费的（重进剪辑页就会出来）—— 拿不准就问用户剪辑页那行字在不在、以余额为准。
    额度不够时剪辑页会说今天的免费配音用完了：可能是当天一个字都不剩，也可能只是剩下的字不够这一句 —— 短一点的句子还配得上，要不就等 UTC 0 点重置；都不是扣钱失败。设置页 / 客服页的试听、客服 / 老师 / 铸卡师念出来的话不在这里头，照旧按字扣
  - 「按住说话」的语音识别按录音时长另扣（见 §4.5）

### 4.4c 余额不足（402）与管理员免扣费
- 管理员账号 **AI 生成免扣费**，界面上会如实写出来
- 余额不足时的整句：「推演一次约 X token，余额 Y 不足——去「我的」页充值」
- 服务端余额不足 → **402 `INSUFFICIENT_TOKENS`**，方舟根本不会被调用

### 4.4d 片段重拍 / 往后延长 / 示例片的计价与「最低用量」（2.64 起）
- 已出片的段下面那一栏叫「修这一段」，里面是「✎ 片段重拍」和「⏩ 往后延长」（延长只在最后一段、电影级出的片上有）。片段重拍勾了「只改其中几秒」也**按整段计价**（整段一起重新生成，时长跟随成片），价钱印在「✎ 重拍这一段（…）」键上，不会因为只改几秒就便宜；延长的价钱印在「⏩ 往后延长」那颗键上
- **带视频输入的出片怎么算钱**（片段重拍、往后延长、示例视频都要付过钱，见 §4.2）：片段重拍按「这一段成片时长 × 2」秒计价；往后延长（只有电影级）和示例视频出片（高清 / 电影级）按「输入秒数 + 输出秒数」计价。延长的输入是被延长的那一段成片，示例视频的输入是挂上去的那段视频（秒数取整，输入按 4~30 秒算）。每秒价：电影级 60,480 token，高清 20,160 token（例：电影级重拍一段 5 秒的成片是 604,800）
- **2.64 起，往后延长和示例视频按方舟「含输入视频的最低用量」报价**：输出超过输入的 1.5 倍时，输入不按实际秒数算，而是按「输出 × 2 ÷ 3，向上取整」秒计价（这是方舟对带视频输入的出片的计价规则）。例：电影级把一段 5 秒的成片往后延长 8 秒，2.64 报 846,720（按输入 6 秒 + 输出 8 秒），2.63 报 786,240；4 秒的成片延长 8 秒，2.64 同样报 846,720，2.63 报 725,760；4 秒的成片延长 15 秒，2.64 报 1,512,000（按 10 + 15），2.63 报 1,149,120；高清拿 4 秒的示例视频出 8 秒，2.64 报 282,240，2.63 报 241,920（延长只有电影级能用，能选 5 / 6 / 8 / 10 / 12 / 15 / 20 / 30 秒；高清示例视频能选 5 / 6 / 8 / 10 / 12 / 15 秒）。输出不超过输入 1.5 倍的，两版报价一样；片段重拍不受影响。输入被抬高时，延长那一栏写「按输入 N 秒 + 输出 M 秒计价」，下面还会多一句「输出 M 秒超过输入视频（K 秒）的 1.5 倍：方舟对带视频输入的出片有最低用量，输入按 N 秒计价」
- **服务器从 2026-10-22 起也按最低用量扣**（与 2.64 的报价同一个式子），所以 2.64 及之后的版本报价就等于实扣。2.64 发版到 10-22 之间那一天服务器还按老算法（实际输入秒数 + 输出秒数）扣，那段时间输入被抬高的延长 / 示例视频出片实扣比报价少，不是扣错，也没有差额要退。**2.63 及更早的版本**没有这条最低用量：输入被抬高时（输出秒数超过输入秒数的 1.5 倍）报价会比实扣低，少报的就是被抬高那几秒的钱（例：电影级 5 秒延长 8 秒，老版报 786,240、实扣 846,720）—— 遇到用户说「扣得比报价多」先问版本，让他更新到最新版；输入没被抬高的，各版报价都等于实扣。实扣以「我的」页余额为准

### 4.5 计费与退款（**这是客服最关键的一节**）
- **AI 客服看得到本人的账**（2026-10-30 起）：问到扣费 / 余额 / 退款时服务器给模型一份本人流水摘要（时间 · 事项 · 数额，不含任务号）；没有退回记录就说目前没有；看不了别人的、改不了账（转人工 billing）
- 契约：**先扣钱、再转发；上游没受理就原路退回**
- 上游非 2xx（400 敏感词 / 429 限流 / 5xx / 501 没配 key）→ 扣掉的**原样退回**（从哪一部分余额扣的就退回哪一部分）
- **任务被受理之后才失败也会退**（新规则上线之后受理的任务：北京时间 2026-10-09 清晨起，2.62 发版那次服务器更新；更早受理的服务器没有记那一笔账，不会自动退）：**只认 AI 那边明说的结局** —— 方舟明说这一发失败了 / 被取消 / 过期作废（排队加生成超过 24 小时方舟自己标过期），真人档（MiniMax）明说「失败」→ 这一发的 token **自动退回、只退一次**，按扣的那两桶原样退（plan 的回 plan、addon 的回 addon）、退给下单的那个账号。
  覆盖普通出片、带参考视频的出片（白模模板套用、片段重拍、延长、示例视频）、电影级样片两步（**两步是两单，各退各的**：定稿失败只退定稿那一笔）、3D 建模、白模化出片那一笔、真人档
- 用户在出片页当场看到的话：「这一发没出成，扣的 N token 已经退回。」；出片前补画过画面的是「视频那部分扣的 N token 已经退回；出片前画好的 K 张画面已按张计费（共 X token）。」；退款还在办的是「……会退回——到账以「我的」页的 token 余额为准。」
- 人不在 App 里时由服务器后台补退（受理 10 分钟后第一次去问，之后问不出结局就逐步拉长到每小时问一次），退了会发一条通知「生成失败，token 已退回」（3D 建模的退款不论在哪儿退的都发）。**不承诺到账时间**，以余额与通知为准
- **还在排队 / 生成中、或者我们这边没等到结果**（App 等超时、断网、盯不住进度、查不到）**本身不算失败，也不决定退不退**：片子多半好好地出成了，用「取回」领回来、不再花钱；
  如果这一发是新规则上线（北京时间 2026-10-09 清晨）之后受理的，最后被方舟（真人档是 MiniMax）明说失败 / 取消 / 过期作废，服务器照样会自动退回（2.62 起人不在会收到通知），不用等 App 那边收到结果；**出成了却没取回**（过期了）的、新规则上线之前受理的都不退，服务器问了 8 天还问不出结局的转人工核对
- **不退的**：AI 出成了（哪怕不满意，或者出成了却没取回、过期了）；
  出片前已经画好的画面（补画设定帧 / 圈选改帧，按张计费）—— 2.62 起，如果 App **当场收到了失败结果**（视频那一发失败，或者补画到一半某张画面失败；App 一直开着、等到了结局，中途切到别的页面也算），已经补画好的设定帧会留在方案上，只要**不关 App、也没有换开别的草稿 / 新流水线**（做同款、套模板也算换），重试就不再收这几张的钱（失败时不会自动存草稿：想过后再来、或要切到别的工程，先点「存草稿」；没存就关掉 App、被系统回收或换了流水线的，这几张要重新画、重新按张收钱；简约模式没有草稿）；
  **没等到结果**（等超时、断网盯不住进度、App 被关掉或被系统回收）、后来才被判失败退款的，这几张**没有留下**，重试会重新画、重新按张收钱（生成键上的报价会把它们算进去）；**按圈选改过的画面任何情况下都不留**：圈选还在的话，重试会再改一遍、再按张收钱；白模化「看画面」那一步；白模化出成了但产物太短不能当模板；
  老师（AI 老师）的生成与教学轮（教学轮在老师开口之前就失败的，那一轮当场退）；新规则上线（北京时间 2026-10-09 清晨）之前受理的任务；服务器问了 8 天还问不出结局的（转人工核对，不自动退）；管理员账号（本来就没扣）
- 九宫格分镜那种「一次画一组图」：先按要的张数预扣，结束时按**实际拿到手的张数**结算：拿到了几张的，多扣的那部分**一律退进套餐额度（plan）那一桶**，不按原来扣的两桶分开退（付费套餐的 plan 月底刷新作废，当时如果用到了永久余额，退回来的这部分要在当月用掉）；一张都没拿到就全退，按原来扣的两桶原样退回
- 九宫格分镜那一组整组被拒（比如分镜没过内容审核）或一张都没画出来时，2.63 起**上一组已经画好的画面会摆回格子里**（不会因为这次失败被清空，那些是付过钱的）；头一次画就失败的，每一格写着这次没画成的原因
- 客服页「按住说话」的语音识别：按录音大小先预扣，识别完按上游给的实际时长结算，多扣的退进 plan（上游没报时长的那一次按预扣算、不退）；上游判定整段是静音的整笔退进 plan（识别成功但没出文字的按时长照算，屏幕上显示「没听到声音」不一定都是静音那种）；上游没接 / 连不上的当场原样退回原来的两桶
- 旧版 App（2.61 及更早）里那句「受理之后的失败不退款」是过时的话：钱照样会退，以余额为准（旧版收不到退款通知，见 §4.10）
- 查询任务状态 `GET .../tasks/:id` 与取产物 `GET /asset` 计费为 **0**
- 每个响应带 `X-Wallet-Plan` / `X-Wallet-Addon` 权威余额头，App 钱包镜像据此同步
- 客户端钱包是**镜像不是账本**；远端模式下 `spendTokens` 是空操作，真扣款在服务端
- 报价与实扣共用同一函数（`segTokens` 等），两仓价目表必须逐条相等，服务端 spec 钉住；**例外（2.64 起，暂时的）**：延长、示例视频在输出超过输入 1.5 倍时，2.64 按方舟最低用量报价、服务器还按老算法扣，实扣比报价少、不会多，没有要退的差额（例：电影级 5 秒延长 8 秒，报 846,720、实扣 786,240；见 §4.4d）

### 4.6 「取回」= 避免二次付费（客服高频）
- 出片是先扣钱再等。方舟各档（极速 / 标准 / 草稿 / 高清 / 电影级 / 白模模板）App 最多等 `max(12分钟, 输出秒×90s + 3分钟)` —— 5 秒段 12 分钟、15 秒约 25.5 分钟、30 秒的电影级段或 30 秒白模模板段约 48 分钟；**这是 App 放弃等待的上限，不是正常要等这么久**；真人档固定等 10 分钟。到点都不是失败，用「取回」领
- 轮询节奏：前两分钟 5 秒一次，之后 10 秒一次
- 到点不算失败，抛 `ArkTaskUnknown`：「等了 N 分钟还没出片。这不是失败：任务还在方舟那边跑，钱在提交那一刻就已经花掉了。」
- 连查 5 次失败：「盯不住这一发的进度了（…）。任务还在方舟那边跑，不是失败：钱在提交那一刻就已经花掉了。」
- **凭据存本机 localStorage，有效期 24 小时**（方舟产物 TOS 签名地址 24h 过期）
- 未过期提示语（方舟档，2.62）：「还剩 X 小时 Y 分钟可以取回——方舟的成片只留 24 小时，过期就没了。这一发的钱在提交那一刻就已经扣了，**万一最后没出成会自动退回**；**取回不再花一分钱**，点「重新生成」是重新下一单、会再花一次。」
  「万一最后没出成会自动退回」那半句只在服务器会退、而且这一发有账（新规则上线 —— 北京时间 2026-10-09 清晨 —— 之后受理）时才说；不然是老的那句「……钱在提交那一刻就已经花掉了，取回不再花一分钱……」
- 卡片一挂上，新版 App 会先问服务器「这一发的钱怎么样了」：已经因失败退了的，卡上直接说「这一发没出成，扣的 N token 已经退回——没有成片可取了，点「知道了」消掉这条就好。」（退款还在办的说「会退回」）；
  已经退了钱的任务也**不会**再出现在「待取回」里（服务器登记表不列它们）
- 过期提示语（方舟档）：成片只在服务器上留 24 小时，过期就取不回来了。**钱分几种情况**：这一发其实失败了的，token 已经（或会）自动退回；
  这一发出成了却没取回的，钱已经花了、无法挽回；服务器还没给结局的，两种情况都说（「如果方舟那边其实是失败了，扣的 token 会自动退回（到账时会通知你）；如果是出成了却没来得及取回，这笔钱就无法挽回了」）；
  服务器一直没能确认结局的（问了 8 天），**没有自动退回**，也不会发通知；本机的取回卡在过期 7 天后（差不多同一时间）会自动清掉，多半已经看不到任务号 —— 用户说「卡上说失败会自动退，过了一周多还没退」的直接转人工，让用户报大概的提交时间和是哪一段（还看得到任务号就一并带上）；新规则上线（北京时间 2026-10-09 清晨）之前受理的那一发没有自动退款这回事，照旧说「已经花掉的钱无法挽回」。
  新版 App 会先查一次「这一发退了没有」再说哪一句；重新生成是再花一次钱
- 真人档（MiniMax）**不许说 24 小时**（我们没量过 MiniMax 留存），过期文案（2.62、真人档失败退款开着时）是「这一发我们不再跟进了：任务号还在下面，如果一直没取回来，**把它发给客服还有机会**。如果上游那边其实是失败了，扣的 token 会自动退回（到账时会通知你）；如果是出成了却没取回，这笔钱就无法挽回了——重新生成是再花一次钱。」
  旧版 App（或服务端关掉了真人档失败退款）还是老的那句「……**已经花掉的钱我们这边退不了**——重新生成是再花一次钱」：真人档失败退款开着时，上游其实失败了的那一发照样会自动退回，以余额为准
- 真人档未过期：「出片通常 1~2 分钟，隔一会儿再点一次。」
- 真人档成片已经出来、只是取下载地址那一步没收到回包时，2.63 起说「成片已经出来了，取下载地址时没收到回包——凭据还在，过一会儿再点「取回」，不花钱。」：照做就行，**不要点「重新生成」**（那是再花一次钱）
- 真人档上游明说失败：这一发的 token **自动退回**（新规则上线起，北京时间 2026-10-09 清晨；运维可以单独关掉真人档的退款（服务端 `MINIMAX_FAIL_REFUND=off`），关掉时新版 App 不会许诺「会退回」；旧版 App 还写着「受理之后的失败不退款」，那句话过时了，以余额为准）；重新生成会再花一次钱
- 取回成功会补扣一次 token（保证一段视频只扣一次，不是零次）；远端模式下真扣发生在提交那刻，取回一分不多花
- 本机自己交的那一发：没过期、也没退款的凭据**不能消掉**（里面躺着还能取回的成片）；服务器说已经退了钱的，过没过期都会给「知道了」（点了先免费再核对一次结局，再收起）；过期的都可以「知道了」消掉。
  从服务器任务登记表补回来的那种（卡上不挂在哪一段上）：没过期也能点「这一发我已经拿到了，不用再提醒」消掉；它退了钱的话点「知道了」直接收起

### 4.7 「圈选白花钱」的防护
- 承接段（第 2 段起）的开头画面由上一段的**真实尾帧**顶替，圈在前半段的修改画出来会被覆盖 → 现在**不跑也不收钱**，并且在按下重炼**之前**就说明
- 页面整句：「另有 N 处落在承接段的前半段（开头画面用的是上一段的真实结尾，不重画）——**不计费**，但你写的要求仍会随出片提示词发出去。」
- 带参考视频的段整句：「这一段带着参考视频，出片时不接受圈选改画面——这 N 处得先清掉才能开炼（它们也不计费）。」
- 剪辑页：「另有 N 处落在已删掉的段上，不计费也不会重拍」
- 提取器：选段外的标记「**不会被采用、也不计费**」
- 铸卡：「少画的那张不会去调出图，也就不计费」
- 价目缺失时**既不报价也不开炼**（`imageTierPriceIssue` / `r2vPriceIssue`），绝不静默按 0 收或静默降级
- 确认卡执行前用同一把尺重算价钱与顺序门禁，对不上整句拒（防「标价 507.6k、实扣 1.0M」）
- 铸卡时卡面没画成、用你的原图顶上的那一张：上游明确拒绝的（敏感词 400、限流、5xx 等）服务端当场退回、不收钱；**没等到回包（超时 / 断网）或者图已经出了却没取回来的，那一张可能已经扣了** —— 以「我的」页的 token 余额为准，不要说一定不收钱，对不上转人工
- 自己传图做卡片（`/custom-card`）：**只用自己的图铸卡这一步不调模型、不扣 token**；页面上几颗可选的键要花 token，价签印在键上 —— 人物卡的「AI 生成图位」（几张图 + 一次对话）、「圈选改图」（一张图）、场景 / 道具卡的「📷 拍摄识别」/「让 AI 填写」（一次对话，约 400 token）。**别说「这一页不收钱」**

### 4.8 生成失败的典型原因与文案
- **提示词含敏感词 → 整个请求 400（`InputTextSensitiveContentDetected`），不是降级而是失败**；「少女」「拥抱」「害羞」等词会被拒
- 当初做精灵图（同一个 Q 版角色六个姿势拼成一张）时，那几种写法被方舟按文本敏感（`InputTextSensitiveContentDetected`）整发拒过 —— 被拒的是那几种写法，不是「一张图里画同一个人好几次」本身：App 自带的「无面部白模三视图」「角色设定规格图」就是同一个角色在一张图里画几个角度，能正常出；一个画面里站着两三个不同的人也可以画（对话正反打的双人镜头就是），只是人多了认人不一定准。遇到这类 400，建议换个写法或拆成一张一张画
- **「参考图没拉到」自动再交一次（2.71 起）**：方舟偶尔拉不到刚传上图床的参考图，提交时当场拒掉。App **等约 20 秒自动再交一次**（界面照旧是提交中），还被拒才报错「有一张参考图方舟没拉到……过一会儿再点一次生成」。这一发方舟没受理，按 §4.5 扣的原样退回，再交也不多扣；出片前补画的画面照常按张算。只认这一种（没过审不重交），只在方舟（Seedance）那几档；2.70 及以前直接报失败、要自己再点
- 「推演失败：…」/「重画失败：…」（截 120 字）
- 演示模式（未连服务端 / 未配 key）：AI 全走 mock，成片是首尾帧渐变。发布页会给每段打标：「✓ 真实影像」或「⚠ 渐变回退」
- 出片成功后自动转存 Cloudinary 换永久地址；转存失败退回方舟直链（24h 有效）并说明「跨境网络下预览可能很慢」
- 段与段的承接：草稿 / 高清 / 电影级三档为了能同时发素材卡形象图，起拍是「参考图 + 提示词点名」而不是协议级硬约束 → **不能说「无缝」「严丝合缝」**
- 想让段与段接得更顺，能做的就这三件（**都做了也不保证无缝**，别替用户许诺）：① 这几段挂**同一张场景卡**（卡面当定场参考图，切镜头之后地点也有图可依）；② **每一段的要求里把地点、时间、光线再写一遍**（每一发都是独立的，模型只看得到这一段的句子和图；场景卡只锁空间、不锁时间和光线，不写就会漂）；③ 出片前在方案台 / 编辑窗**看一眼首帧**是不是接着上一段。别另编办法（这里没写的写法、咒语一律不推荐）。依据：2026-10-04 付费验证，两段直出人物与接缝都好，第二段切镜之后从「雨夜、暖灯的旧书店」漂成了「白天的大图书馆」，因为第二段的要求没写地点和时间
- 圈选改帧是**软引导**，不能说「一定按你圈的改」

### 4.9 电影级「样片」（2.62 起）
- 是什么：电影级的段可以勾「📼 先出样片（480p 预览，满意再定稿成 1080p）」。先花小钱出一条 480p 样片，看场景、镜头、动作对不对；满意再把**同一份样片**定稿成 1080p 成片（画面、动作、声音都照样片，**不重新抽卡**）；不满意就改了重出样片（每次按样片的价），省下成片的钱
- 两步是**两单、各自计费**：样片按电影级 480p 算（例：4 秒 180,621、5 秒 225,776；出片前补画的画面另算），定稿按 1080p 另一个价算（例：4 秒 997,920、5 秒 1,247,400）。定稿的时长、画幅、内容都照样片，一样都不能改
- ⚠ 样片 + 定稿加起来比直接出一段 720p 电影级（5 秒 507,600）贵，成片是 1080p。省钱省在「不满意就只重出样片」那一步 —— **别说「样片模式更便宜」**
- 定稿期限：样片出来之后约 **7 天**内可以定稿（方舟的样片只留 7 天，我们在到期前 1 小时截止），卡上有倒计时；过了期就不能再定稿，要成片只能重新生成（重新计费）。只能定稿**自己在启梦里出的**样片
- 定稿之后：上一版（480p 样片）在「修这一段」的「还原上一版」里；定稿过又还原回样片的，1080p 成片也在「还原上一版」里，点回去就行，不用再花一次定稿的钱
- 1080p 成片存进图床时会转成通用格式（方舟出的是 10 bit 的 H.265，很多手机的 App 内播放器解不出画面）；**转好之前（一般几分钟）个别手机可能只有声音、没有画面**，等几分钟再看；如果过了十几分钟、重新打开仍然只有声音，可能是转格式没成功（服务器会按原格式存下来），请带上作品 / 第几段转人工核对，别反复重新出片
- 用不了样片的：白模模板段、往后延长出来的段、自定义带参考视频的段、真人档；别的档位没有样片模式（「「…」档没有样片模式（只有「电影级」有）」）；服务端太旧时说「这台服务器还不支持样片模式（服务端需要更新）」。**免费版（没付过钱）用不了**，两步都会被服务端挡下
- 失败退款两步各退各的；退款通知里分别写「一段样片（480p 预览）没出成」「一次样片定稿（1080p）没出成」

### 4.10 旧版 App（2.61 及更早）用户会遇到的旧说法
服务端分不出新旧包，新规则（北京时间 2026-10-09 清晨上线）对旧版 App 一样生效，而旧包里写死的话还是旧的。用户在旧版上问到这些，**先请用户更新到最新版**（新界面 2.62 起就有，见 §7.2）
- **免费用户每一段默认还是「标准」**，标准 / 高清 / 真人档都点得动；推演（对话 + 出图）与出片前补画设定帧照扣（画出来了，不退），到出视频那一发才被服务端拒（「免费版只能用「极速」「草稿」出普通片（档位里看不到「草稿」的话，请先更新 App）……」）。换到「极速」或更新 App 之前，每试一次都会白花推演与画帧的钱
- **「我的」页的额度说法是旧的**：套餐列表写着免费版「300k token/月 · 注册即得，每月刷新」、标准套餐「2M token/月 · 约可生成 15 段标准档视频」、专业套餐「8M token/月 · 重度创作，约 60 段标准档」，电影级置灰那句写「「电影级」单段消耗超过免费版整月额度（300k），升级套餐后可用」。**余额数字本身是服务器给的、是对的**；实际规则见 §4.4
- **旧包没有「草稿」**。2026-11-24 13:00（北京时间）起极速 / 标准停用，旧包会把拒绝原样显示成一串 `Ark /contents/generations/tasks 400: {…}`（里面那句话说了请换档、看不到草稿先更新 App）—— 那之后**免费用户在旧包里一档都用不了**；付过钱的在旧包里还能用高清和真人档，开了付费套餐的还能用电影级（只充值过的见下一条）
- **旧包只认「开没开付费套餐」，不认「充值过」**：只买过充值包、套餐还是免费版的人，在旧包里电影级一直是灰的（「升级套餐后可用」）—— 不用为此买套餐，更新到最新版就能用（2.62 起就认充值）；高清在旧包里本来就点得动
- 旧包还写着「受理之后的失败不退款」—— 钱照退，以余额为准；但旧包**收不到**「生成失败，token 已退回」这条通知（2.60 及更早也收不到同款奖励的通知，币照到）

## 5. 语音 / TTS

### 5.1 SettingsVoicePage（`/settings/voice`，标题「铸卡师的声音」）
- 三块：音色列表（点即试听并选中）、语速、语调指令；**每点一次音色就用云端语音试听一次，按字符扣 token**（试听句 26 个字符，约 858 token）
- 试听台词固定：「欢迎来到卡片工坊，把你的素材交给我，我为你炼成卡片。」
- 语速滑杆：−30 ~ +20，步长 5，标尺 0.70×慢 / 1.00× / 1.20×快；可「恢复跟随音色」
- 语调指令：自由文本，**上限 120 字**，可「恢复默认」；这个旋钮比换音色更管用
- 「调和」标签的混音音色**语调指令对它无效**（那是 2.0 专属）

### 5.2 音色清单
- 默认：**清冷高雅 2.0**（rate −10，支持表现力增强）
- 5 个混音配方（御姐+知性+女友 / 古风少御+御姐 / 古风少御+知性+柔美 / 御姐+温柔淑女+小雅 / 俏皮+御姐+女友），统一 rate −20
- 单音色 2.0（11 个）：高冷御姐、知性女声、知性灿灿、魅力苏菲、温柔淑女、清新女声、小何、古风少御、Vivi、顾姐、魅力女友、TVB女声
- ICL 角色扮演档（6 个，支持表现力增强）：成熟姐姐、成熟温柔、理性圆子、邪魅女王、温柔女神、病娇姐姐
- 三条选型硬约束：只收 2.0 音色（1.0 未开通）、**绝不收 IP 仿音**（法律风险）、一律中文音色

### 5.3 云端 vs 系统合成器降级
- 试听打 `POST {API_BASE}/api/tts`；返回 404/501/401/403 时**真的退回系统内置合成器**
- 页面常驻一句：「没配云端语音时退回系统内置合成器（需装中文语音包）。」
- 两句错误文案：
  - 「这台设备既没有云端语音，系统也没装中文语音包，试听不了」
  - 「云端语音没出声（状态码）：稍后再试，或到火山控制台看额度」
  - ⚠ 火山控制台是运营方的后台，用户没有、也不用去。括号里是 402 = token 余额不足（去「我的」页看余额）；429 = 今天的用量到了每日上限（UTC 0 点重置），或一分钟内点得太快（30 次/分钟），等一会儿再试
- **「铸卡师不出声（嘴在动没声音）」按顺序查**：① 声音开关是不是关着（铸卡师对话框上显示 🔇；在客服页或上课页关掉的也算，是同一个开关）；② token 余额不足或今天的用量到了每日上限 —— 这时云端语音不出声，会退回系统自带的语音；③ 系统没装中文语音包（退回系统语音时就没声音）；Windows 上装完要完全退出浏览器再开（语音表在进程启动时枚举一次）
- `/api/tts` 必须走 `API_BASE`，不能同源相对路径（Capacitor SPA 回退返回 200+HTML）
- 服务端 TTS：`POST /api/tts` 必须登录，按用户限流 **30 次/分钟**，text ≤300 字（超出截断）；每次合成按字符扣 token（每个字符 33），算进每日上限，没出声的自动退回。例外是新版剪辑页的旁白配音（看得见「配音免费，每个账号每天 1000 字」那行小字的版本）：不扣 token、不算进每日上限，每个账号每天 1,000 个字符，用完不会转成扣 token，见 §4.4b

### 5.4 人物卡的声音样本（跟读录音）
- 长按按钮照着示例句念，**2~15 秒**（Seedance 参考音频硬窗口），到 15s 自动停
- 太短提示：「太短了（X.Xs）——按住别松，照着示例词念够 2 秒再放手。」
- 麦克风权限失败提示：「App 版本 ≤2.29 的安装包没带录音权限，升级到新版后在系统弹窗里点允许；拒绝过的话去系统设置 → 应用 → 启梦 → 权限里打开麦克风。」
- 生效条件：出片走「草稿 / 高清 / 电影级」档（2.62 起多了草稿）、台词写在引号里
- **声音样本只存本机 IndexedDB（侧库），不跨设备、不随分享**
- 工作流的首尾帧承接段**带不了音色参考**（协议互斥，不是漏做）
- 音色点名句放不下时会明说「放不下就不发，并告诉你把要求写短些就能带上」

- 三种情况下三颗分享键**全部禁用并说明原因**
  - 还在上传中/没连上服务器：「现在分享出去的链接别人打不开。等它传完再分享。」
  - 已被平台下架：「这条已被平台下架，链接别人打不开，所以先不能分享。原因：…」
  - 私密作品：「链接只有你自己打得开。想给别人看，去编辑里改成「凭链接可见」或「公开」。」
- 官网预览页看不到的兜底文案：「这条视频不存在或已下架。去启梦 App 里看看更多作品吧。」

### 6.4 互动与防刷
- **播放计数**：要真看够 **3 秒**（`PLAY_MIN_SEC`，按 currentTime 增量累计）且一次会话只记一次
- 首页用倍速或按住两侧快进时（2.64 起），这 3 秒按视频内容算、不按真实时间算：2 倍速下实际看约 1.5 秒就够；拖进度条跳过去的那一截不算
- **点赞**幂等；离线模式把 likedIds 落盘
- **收藏跟着账号走**（v2.41 起），此前只活在内存里、杀掉 App 就没
- 评论正文服务端上限 **1000 字**
- 弹幕上限 **40 字**，走服务端，**不做乐观插入**（真等回包）
- **不想看弹幕（关掉弹幕显示）**：在首页点右侧「发弹幕」打开弹幕输入条，最左边那颗弹幕图标就是总开关（读屏念作「关闭弹幕显示 / 开启弹幕显示」），点一下就不再显示弹幕（关着时右侧「发弹幕」图标上有一道斜杠），再点一次重新显示。对首页每一条都生效，只记在这台设备上、不跟账号走；关着时发一条弹幕会自动打开。没登录时点「发弹幕」会先去登录页。长按菜单里的「清屏观看」不会关掉弹幕。这不是拉黑：只想不看某一个人的，才拉黑他（双向，见 §2.9）

### 6.6 举报与下架
- 举报入口在**作品 / 评论 / 弹幕**三处（2.71 起的版本另有人格市场里别人的人格，见下一条），离线模式整块不渲染。作品的举报在作品详情页（2.71 起是标题下那一排的第五格、右上角「⋯」里也有一行；2.70 及以前在正文里「拉黑」旁边）；2.64 起首页按住画面中间弹出的「更多操作」里也有一行「举报」，同一套理由和规矩（自己的作品没有这一行）；别人的主页上只有「拉黑」、没有举报
- **人格也能举报（2.71 起的版本）**：数字人人格市场（设置 →「🎭 数字人人格」，`/support/personas`）里每张**别人的**人格卡上，作者那一行（「@作者 · ⬇ 下载数」）末尾有一个小字「举报」；自己做的人格上没有。理由、补充说明、同一个人格只能举报一次、限流、没登录要先登录、离线模式没有，这些规矩与作品的举报完全一样。2.70 及以前的版本人格卡上没有这个键：请更新到新版，或转人工 / 发信到 support@ideahubs.org 说明是哪个人格。人格被举报之后，管理员只能**下架**或**驳回**，**不会直接删除**：下架之后它从人格市场里消失，收藏过的人在「已收藏」里也看不到了；作者在「我的」页签里还看得到，但不能再把它设成公开（想申诉就转人工）；要彻底删掉由作者自己删。⚠ **数字人形象（Live2D）市场、声音市场里的声音模板、AI 客服自己的回答，现在都还不能在 App 里举报**（服务端还没有这几类）—— 别说有入口；遇到这类内容请转人工或发信到 support@ideahubs.org
- 8 个理由：涉及未成年人（排第一，2.46 加的）/ 未经同意的私密影像（2.51 加的；本人也可以不登录直接走 ideahubs.org/takedown）/ 色情低俗 / 血腥暴力 / 人身攻击·辱骂 / 垃圾营销·刷屏 / 侵权·冒用他人作品 / 其他
- 补充说明选填，最多 500 字（与服务端上限相同）
- 成功回执：「已收到，管理员会尽快处理。」
- **同一个人对同一个对象只能举报一次**（服务端 409，UI 如实说「你已经举报过了」）
- 举报限流：10 次/分钟 + 50 次/24 小时（按账号）
- 自己的内容不显示举报按钮（该删不该举报）
- 管理员三种处置：**下架（takedown）/ 驳回（dismiss）/ 删除（delete）**，但不是每一类都三样都有：作品三样都有；评论、弹幕**没有下架**（只能驳回或删除）；人格**没有删除**（只能下架或驳回）
- **下架只对别人生效**：作者自己在首页看那条片子与平常毫无区别，但必须看得见下架状态与原因
- 下架与可见性是两个互不顶替的开关：作者把 visibility 改回 public 也没用

### 6.7 保存到本地（作品详情页，2026-09-07 上线）
- 入口**同一颗判据**：2.71 起是详情页右上角「⋯」里的「保存到本地」、分享面板第四项「保存到本地」，自己的作品（或离线时）标题下那一排第五格「保存」也是它；2.70 及以前是详情页正文下方一颗整宽键「保存到本地」（多集作品写「保存这一集到本地」）加分享面板第四项。2.64 起首页按住画面中间弹出的「更多操作」里也有「保存到本地」（旁边写「在详情页里选」），但它只是把你带到作品详情页，在那里选、规矩完全一样（别人的作品上也看得到这一行，到详情页照样存不了）；首页右侧那颗分享键的面板里没有这一项
- **只有 `isNative()` 为真（装了 APK/AAB 的安卓端）才画这颗键**：浏览器里 @capacitor/filesystem 的 web 实现会把文件写进 IndexedDB，「保存到手机」是假的，所以那条路上**整颗键不画**，也不画成灰的
- **只能保存自己发布的作品**（判据 `videos.isMyVideo` 一处，**按 userId 比，不是按昵称** —— 昵称允许重名也能随手改，2026-09-08 评审把这道闸从 `isMyAuthor` 换掉了）
- ⚠ **别人的作品上这颗键仍然画得出来**，点下去才拒（「只能保存自己发布的作品。」，2.71 起这句显示在播放器下方；分享面板里那一项是灰的）。用户问"为什么有这个按钮却存不了"时照实说：这一版只开放给作者本人，按钮没有按作者隐藏。⚠ 不要说"别人的作品没有这颗键"——那是旧稿，与实现不符
- **被平台下架的作品谁都不给存，包括作者本人**（「这条已被平台下架，不能保存到本地。」）
- 还在上传 / 没连上服务器的作品存不了（没有可下载的文件）；只有首尾帧、没有成片的那一集也存不了
- 互动分支作品**没有单条成片**，面板上二选一：「只存刚看的走向」/「存全部分支」，一段一个文件
- 多段作品会存成**多个文件**，不是一条完整长片（App 里**没有**服务端合并这一步）
- 落点是 **App 的缓存目录**（`Cache/ideahub-downloads/<作品 id>/`），**不是相册**：App 目前没有做直接写相册这一步，所以流程是「先存进 App，再点每一行的『分享 / 另存为』，在系统面板里选相册或文件管理器」
- ⚠ 缓存目录**系统在空间紧张时可能清掉** —— 面板上明说了「存好之后请尽快选个去处」。用户抱怨文件不见了，先问有没有走完「另存为」那一步
- 文件名形如 `AIGC-qimeng-20260830-a91c3f-P2-03-3f8d2e1f.mp4`：`AIGC-` 前缀是**文件一级的 AI 标识**（见 10.5），后面依次是作品日期 / 作品短码 / 第几集 / 第几段 / 地址短码。纯 ASCII（中文名会被系统分享面板和 Cloudinary 双双拒掉）
- 线上相当一部分成片是剪辑页导出的 **vp9 webm**，安卓相册应用多半打不开 —— 面板会提示「保存时选文件管理器更稳」。⚠ **不许说 App 能转成 MP4**：那颗键在 2026-09-07 评审时撤掉了（它会对每一段打一发派生地址的 HEAD、当场触发计费转码），记在 `docs/backlog.md` 等拍板
- **一次给多个文件**时系统按「任意文件」处理，相册可能不在候选里；想进相册就一个一个来
- 点「停止」= **后面那些不再开始**；已经下完的都留着，正在下的那一段会跑完并留下（流量已经花掉了，不销毁一件已经成了的东西）
- 重复保存同一条**不重下、也不覆盖**；关掉面板**不会**停止保存（原生线程照跑，全局胶囊接管）
- 占用与清空在**设置 → 存储**的「已保存的视频」那一行（与「清理缓存」是两颗键：那颗清的是没人引用的中间文件，这颗删的是用户特意存下来的成品）；正在保存时点清空是**整句拒**，不是清了 0 个
- ⚠ 顶部那条存储用量条走 `navigator.storage.estimate()`，**数不到**原生缓存目录里这些文件；「已保存的视频」那一行才是它们的量

### 6.8 作品详情页（2.71 起重做）
- **从上到下**：顶栏（返回、分享、「⋯」）→ 满宽播放器 → 弹幕条 → 标题（点右侧箭头才展开简介和话题；2.70 及以前简介一直摆着）→ 作者条（别人的作品「+ 关注」，自己的「编辑」）→ 一排「点赞 · 评论 · 收藏 · 分享 · 举报」→ 评论卡 →「做你自己的版本」卡 → 相关作品（TA 的更多作品、同分区）；最底下常驻「说点什么…」+「做同款」
- **「⋯」更多操作**：倍速 0.75×~2×（离开这页回 1×，与首页各管各的）、全屏 / 转屏观看、保存到本地（装好的 App 才有）、举报、拉黑（这两行自己的作品和离线时没有）。全屏后左上角「退出全屏」或按返回退出
- **弹幕**（2.71 起详情页也有）：「弹幕 N」、开关（与首页同一个）、「发条弹幕…」；只在第 1 集、已解锁时有。「弹幕 N」2.72 起是这条作品的总条数（拉黑的人不算；2.71 条数多时写「N+」）
- **照这条做的同款**（2.72 起）：有人照这条做了同款（非私密、没下架、不算作者自己的）时，相关作品上面多一块「照这条做的同款 · N」
- 那一排第五格：别人的作品是「举报」，自己的作品或离线时换成「保存」。**评论**卡露最新一条，点它、点「评论」或底栏「说点什么…」都打开与首页同一个评论框（2.70 及以前评论和输入框铺在页面里）
- **做同款**在底栏右边（不花钱；这一集锁着或没有分段剧本时不出现）。2.70 及以前：正文里一颗整宽金色「做同款：同一份分段剧本…」，举报 / 拉黑在正文一行小字，别人的作品顶栏有「我也要创作」（2.71 撤了）。卡组的「🎴 用这套卡去创作」2.71 改叫「带着这套卡去工坊」，和「查看制作过程」都在「做你自己的版本」卡里
- **付费集**（2026-08-31 前设过付费的老作品）：锁着的那一集用模糊封面挡住、写「本 P 为付费内容 · N token」；锁着时没有弹幕、全屏、做同款、制作过程。扣费疑问转人工

### 6.9 手机返回键：全屏、评论框、抽屉
- **全屏里按手机返回键**（作品详情页、首页）：2.72 起只退出全屏；2.71 会直接退出这一页（点左上角 ✕ 退出没问题）。**评论框、底部弹出的面板、确认框开着时按返回**：2.73 起先关它们、留在这一页；2.72 及以前评论框开着时，收起键盘后再按一次返回就离开了这一页。正在提交、删除的那一会儿按返回不关。**新手引导、「圈出要改的地方」画板、AI 客服「我的工单」开着时按返回**：2.74 起也是先关它们（引导关掉后留在这一页，「我的工单」回到对话）；2.73 及以前按返回会直接离开这一页

## 7. 设置页

`/settings`（「我的」页右上角进）只是入口列表，每个功能一页（2026-08-27 拆分）；2.63 起每一组上方写着组名，从上到下是 **个性化 / 账号 / 这台设备 / 帮助与 AI 伙伴 / 协议与须知 / 管理**（最后一组只有管理员看得到）。2.62 及更早没有组名，只是几个框

**个性化**
- 🪪 **编辑资料**（`/settings/profile`）— 头像 · 昵称 · 简介
- 🎙️ **铸卡师的声音**（`/settings/voice`）— 行上显示当前音色名
- 🎨 **画面质量**（`/settings/quality`）— 行上显示当前档 + 「只影响 3D 工坊」
- 🌐 **语言 · Language** — 跟随系统 / 简体中文 / English 三选一，切换不用重启、在跑的出片不受影响；手机桌面图标上的名字跟着手机系统语言走，这里切不动它

**账号**
- 🚫 **已拉黑的人**（`/settings/blocked`）— 看名单 · 随时解除（拉黑跟着账号走，换设备还在）

**这台设备**
- 🧹 **本机缓存**（离线模式下叫「存储」）（`/settings/storage`）— 「查看用量 · 清理中间文件」
- 💡 **新手引导** — 弹确认窗，「恢复」= 把所有引导重置成没看过；**只清这台设备**（引导状态存 localStorage，不上服务端）
- 📦 **版本**（这一行没有别的标题，直接写着「版本 X.XX（versionCode）」）— 侧载包下面一行小字「可以检查有没有新版本」，右边有「检查更新」；从 Google Play 装的写「由应用商店负责更新」、没有按钮（见 §7.2）

**帮助与 AI 伙伴**

- AI 客服页 **2.76 起**：输入框下面写着「每问 ⚡400，开着语音另按字计」（数与 §4.4b 同源）；装了人格时第一句开场白用人格自己写的，上面一行小字「人格「X」的开场白 · 回答你的仍是启梦官方 AI 客服」；小梦有时会在回答下面给一颗「带我去：某页」键（点了直接跳到设置 / 钱包 / 形象 / 人格 / 创作中心 / 模板 / 草稿 / 缓存 / 检查更新 / 我的工单）或 2～4 颗选项芯片（拿不准时先问一句，点一下等于把那句话发出去、照常算一轮 400）—— 这两样要服务端 2026-10-30 之后的版本；👎 之后能选 回答有误 / 有害或不安全 / 违法违规 / 侵权 / 其他 提交举报（以工单形式交给人工，一条只能举报一次）

### 7.2 更新机制（关键区分）
- **2.64 是安全更新，请尽快更新**：2.64（2026-10-21）修复了 App 内置网页组件（Capacitor）的一个高危安全漏洞，2.63 及更早的版本都没有这个修复。这一版**不是强制更新**（弹层上能点「以后再说」），但用户问「要不要更新 / 这次更新了什么」时请建议尽快更新：「我的」右上角进设置，「这台设备」那一组「版本」那一行点「检查更新」→「立即更新」；应用内更新不成的，去官网下载页 ideahubs.org/download 下载安装（见 §7.3）。只说到「修复了一个安全漏洞」这一层：漏洞的原理与利用方式不对外讲，也不说谁被攻击过、数据泄露过（我们没有这样的信息）；担心自己账号安全的转人工
- **两个渠道**：`sideload`（自己发的直装包，**有自更新**）与 `play`（上架包，**没有自更新**，拿到的是会 reject 的空壳）
- Google Play 政策禁止应用自己下载安装 APK
- 侧载包：设置页版本行显示「可以检查有没有新版本」+「检查更新」按钮；上架包显示「由应用商店负责更新」，**不显示按钮**
- 启动时**延后 3 秒**自动查一次，查不到一律安静收场；手动检查失败会把原因说出来（区分「已经是最新版本」和「检查失败」）
- **更新弹窗里的说明 2.76 起只写当前这一版**、按界面语言只画一种；装着的版本与新版之间跳过的几版折在「还有 N 个版本的更新你没装过」里，点开才列；设置页「这台设备」多一行「更新记录」能看最近几版各改了什么（上架包没有这一行；老清单没有这一项时写「没取到更新记录」+ 重试）。2.75 及以前弹窗里是 2.62 起全部版本、每版中文在前 —— 用户说「更新说明太长 / 英文要翻到后面」就是那个
- 普通更新：用户点过「以后再说」的版本，开机那次自动检查不再弹，出了更新的才再提（「必须更新」的那种版本不认「以后再说」，见下一条）
- **必须更新（强制更新）**：2.63 起的侧载包认这一条。哪一版设成必须更新由我们发版时决定（**2.63、2.64 这两版本身都不强制**；是不是必须更新以 App 里的弹层为准，关得掉的就是普通更新）；遇到时弹层标题是「需要更新到 X.XX」，写着「你手上这一版已经停止支持了，更新之后才能接着用。」，**关不掉、没有「以后再说」**，只能「立即更新」（失败了点「重试」）。
  另外留着两条备用路：「下不动、装不上？在浏览器里打开官网下载页」（ideahubs.org/download）和「官网也下不动？从 GitHub 下载这一版（备用，国内网络可能打不开）」。2.62 及更早的包不认这一条，遇到同样的版本仍是普通更新提示（能点「以后再说」）。用户问「以后会不会强制更新 / 不更新行不行」：普通版本可以先不更新；被标成必须更新的版本不更新就用不了，那时弹层上一定留着官网与 GitHub 两个下载入口
- 更新走原生 HTTP（不走 WebView fetch，避免跨域）；下载后按 sha256 校验整包。2.63 起更新清单不完整（缺校验值）时一律不下不装：手动检查会说「更新清单不完整，稍后再试」，过一会儿再查就行
- v2.43 起**下载更新支持断点续传**：网络类失败（超时、断网、连不上、下载服务器 5xx / 408 / 429）会自动接着下，最多连试 5 次。地址上没有这一版的包（其它 4xx）从 v2.43 起就当场停下；下载的文件校验不通过、拉不起系统安装器一直不重试。2.64 起，下载途中手机存储写不进去（多半是空间满了）也当场停下，不再白等几轮重试。这些都由手机上装着的那一版决定，从 2.63 及更早往 2.64 更新时还是老做法（具体说法见 §7.4）
- 已知坑：**用同一个版本号发第二份内容 → 已下载过旧包的用户永久更新不了这一版**（CDN `max-age=1y, immutable`），屏幕上那句校验不通过（2.63 及更早写「校验不通过（可能没下完或被中间人改过）」，2.64 起写「下载的文件校验不通过，已经丢掉了（可能没下完整，或者内容被改过）。再点一次会从头重下。」）指向的是不存在的原因；出路是涨版本号重出包
- 已知坑：**出包忘涨 versionCode → 已装用户永远收不到更新**（更新检查靠这个整数判新旧）

### 7.4 检查更新 / 更新弹层的各种说法（2.64 起按界面语言）
- **检查更新查不成**：设置页「版本」那一行点「检查更新」后，下面的小字写「检查更新失败：连接超时，网络太慢或者断了」「检查更新失败：连不上服务器，看看网络通不通」「检查更新失败：网络断了」「检查更新失败：版本清单取不到（HTTP 数字）」「检查更新失败：版本清单读不出来」—— 都是网络或服务器那头没查成，**不等于没有新版**，过一会儿再点「检查更新」；「更新清单不完整，稍后再试」同理。2.63 及更早这里写「检查更新失败: 」后面跟一串英文原话，意思一样
- **更新弹层里下载 / 安装失败**：⚠ 这些话由**手机上装着的那一版**说 —— 从 2.63 及更早往 2.64 更新时看到的还是老说法（见下一条），装上 2.64 之后再往后更新才是这一套。「下载超时了：网络太慢或者断了。」「连不上下载服务器，看看网络通不通。」「下载到一半网络断了。」「下载服务器暂时出错了（HTTP 数字）。」「这一次没下完（网络断了几次）。」后面会跟一句「已经下好的 N MB 留着了，再点一次会接着下，不用从头来。」（或「这一次一个字节都没下到。」）—— 换个网络点「重试」，接着下、不从头来；「手机存储写不进去，可能是空间满了：先腾出一些空间。」—— 先清出空间再点；「下载失败（HTTP 数字）：这个地址上没有这一版的包了，等下一版出来再更新。」—— 再点也没用；「下载的文件校验不通过，已经丢掉了（可能没下完整，或者内容被改过）。再点一次会从头重下。」；「安装包下好了，但拉不起系统安装器。可以再点一次试试（不用重下）；还不行的话，在浏览器里打开官网下载页 https://ideahubs.org/download 手动安装。」；「还没允许这个 App 安装应用：先去开启「允许安装未知应用」，再点一次。」「打不开系统的授权页：请到系统设置里给这个 App 打开「安装未知应用」。」—— 照着去系统设置开权限。认不出的原因照原样显示
- **2.63 及更早**的更新失败提示是原生直接拼的，开头常带一个英文原词（真机遇到过「timeout。已经下好的 46.2MB 留着了，再点一次会接着下，不用从头来。」），校验不过写「下载的文件校验不通过，已丢弃（可能没下完或被中间人改过）」，地址上没包写「下载失败（HTTP 404）。这个地址上没有这一版的包了，等下一版出来再更新。」—— 与上一条是同一类原因，照同样的办法处理（网络问题换个网络点「重试」、空间满了先清空间、反复校验不过的转人工）。从 2.63 往 2.64 更新时看到的就是这一套

## 8. 存储与离线

### 8.1 SettingsStoragePage（`/settings/storage`）
- 显示「已用 X MB / 可用约 Y MB」+ 进度条（来自 `navigator.storage.estimate()`）
- 说明按模式分两句
  - 远端模式：「作品与卡片已同步到服务器，换设备登录同一账号即可看到；这里是它们在本机的副本，加上生成过程中的中间文件。」
  - 离线模式：「作品与卡片存在本机数据库里。AI 生成的画面体积较大，空间不足时请删除旧作品。」
- 「清理缓存（可释放 X MB）」按钮 + 确认窗；确认窗承诺：「**只删生成过程中留下的、已经没人用的中间文件。未发布的草稿和还没传上去的作品不会动。**」
- 没得清时明说「没有可清理的中间文件」，不做假忙

### 8.2 清理的真实边界
- **只清两类键**：`merged:<id>`（剪辑页合成出的成片，几十 MB）与 `model3d:<id>`（AI 生成的 3D GLB，36MB 级）
- **只扫 24 小时以前的键**（刚合出来还没保存的成片不碰）
- 永不碰：未发布草稿（正文+索引）、待上传队列、账号库、互动数据、弹幕、设置
- **引用收集不完整时一个都不删**
- 历史事故（v2.42 修）：「清理缓存」可能删掉还没传上去的成片，触发条件是冷启动没连上服务器、或这台手机上换过账号

### 8.3 存储满 / 写入失败
- IndexedDB 写失败（配额满或隐私模式）返回 `false`，**调用方必须报给用户，不能静默当成保存成功**
- 待取回凭据存 localStorage，配额满时内存那份还在（这次会话仍取得回，重启才丢）

### 8.4 离线 / 本地模式
- 开关是 `VITE_API_BASE`：有值=远端模式，空=离线模式（走 IndexedDB）
- **配了地址 ≠ 跑在远端**：服务器打不通时整体回退 IndexedDB，照常能登录、炼卡、看演示作品
- **演示作品（三条）只在离线模式出现，且明确标成示例**（2026-09-17）
  - 首页 / 详情页 / 分区页 / 个人页网格四处都挂「示例 · 离线」角标（判据 `videos.isSeedWork`）
  - **播放 / 点赞 / 收藏 / 分享数一律 0，评论一条都没有**：原来那些数字与评论是编的（48213 播放、3120 赞、几条夸奖），已撤
  - 标题 / 简介 / 作者显示名 / 演示弹幕按界面语言翻；**剧情、段标题、作者身份名仍是中文**（「做同款」会把剧情原样发给模型）
  - 它们**不落 IndexedDB**：每次开机现造 —— 老设备上存着的那份（中文标题 + 编出来的计数）会在开机时被自动洗掉
- 登录页底部按模式给不同承诺
  - 远端：「已连接服务器：账号与作品跨设备同步。」
  - 离线：「当前为本地账号：数据存在这台设备上，换设备不同步。」
- 离线模式下：通知/举报/注销/充值全部不可用或整块不渲染
- 「配了服务端但这次没连上」时充值会拒绝并说「当前未连接服务器，暂时无法充值，请联网后重试」（订阅那条是「…暂时无法订阅…」；不会做假余额）

### 11.2 充值订单
- 订单状态机：`created → paid → settled`，或 `closed` / `failed`
- `GET /api/pay/config` 返回 `payable`；**`payable=false` = 现在收不了钱，UI 必须说出来**

### 11.3 点数 / 悬赏 / 人格购买（官网产品线）
- 服务端有 `points`（虚拟点数）、Bounty、Persona 购买等模型
- 服务端明确写着：「★这是平台【虚拟点数】，不是真钱：无现金价值，不可提现/兑换，不接任何真实支付。」
- App 里能逛数字人人格市场：付费人格会标出**积分价**（💰 N，买过的标「已购」），自己做人格时也能标一个积分价；但 **App 里不能买** —— 付费人格要先在官网购买，买过之后 App 里就能装上用。积分是官网的虚拟点数，和 App 的 token 钱包是两套：**不能用 token 买**，也不能提现或兑换；悬赏、积分的其它用法都只在官网

### 11.4 其它服务端事实
- 通知类型：含官网侧的 LIKE/COMMENT/MESSAGE_REQUEST_* 等；App 只筛 `BRANCH_NOTIFICATION_TYPES` 列出的那几类 —— 作品互动 BRANCH_*、生成失败退款 GEN_TASK_REFUND、平台通知 ADMIN_NOTICE、客服工单 SUPPORT_*、老师人格 TUTOR_*，完整表见 §6.5

- 用户协议同意留痕：`POST /api/me/accept-terms`，**服务端只存不判**，是合规留痕不是门禁

## 12. 启梦老师（用自己的教材做一位 AI 老师；官网和 App 里都能上课）

- 「启梦老师」有两个面：**官网** ideahubs.org/tutor（功能最全）与 **App 里的「AI 老师」**（设置页「帮助与 AI 伙伴」那一组的「🎓 AI 老师」、创作中心第四扇门「人物 → 老师」，App 内路由 /tutor）。同一个启梦账号、同一份课程与进度、同一份 token 钱包 —— 网页上建的课 App 里能接着上，反过来也一样
- App 里能做的：看自己的课程列表；用 **.md / .txt** 建课（选文件，或直接粘贴讲义文字；定老师的名字 / 教学风格 / 严厉度；看报价再生成）；上课（按阶段看文字卡、在下面问老师、自检、答对三分之二进下一阶段）；「整理一下」让老师把这节课学到的记下来。生成与整理都是长活：可以退出那一页，结果会在胶囊 / 通知里
- App 里**不能**做、要去官网：传 PDF / PPTX / DOCX（App 只收 md / txt；**相册图片也不行**，没有文字识别）；把老师发布到市场；评分；合并新版；复习卡与到期回访自检；修订审阅（老师学到的东西要在官网逐条点头才落进人格）

- 反向：勾了「同时发布为启梦人格」的老师才会出现在数字人人格市场里、才能装进看板娘 / 客服页的数字人 —— 装进去的只是说话风格（口头禅、语气、开场白、边界），**不会带着课件内容**；没勾的老师在人格市场里看不到，这是正常的，不是丢了
- 离线模式（App 没接上服务器）下「AI 老师」整页只说「需要联网」：老师、进度、对话都在服务端，本机不存一份，接上服务器就都在
- 通知：别人给你发布的老师打分 / 留言、你在学的老师出了新版、有阶段该回访了，App 通知页都收得到；点开落到那门课的上课页或课程列表（评分与留言本身要去官网看）
- 钱：价目 App 与官网同一张表。App 里**只有「生成老师」那一步当面给报价**（受理那一刻按整份报价扣）；上课时每问一次老师、每点一次「让老师讲这一段」（一轮教学，约 400 token）都按次扣；「整理一下」每次约 600 token —— **除了自己点，老师还会自动整理、照样扣约 600**：每满 8 个一问一答一次、自检通过进下一阶段时一次、最后一次对话之后 30 分钟没动静时一次（上次整理之后既没有新的提问（含官网圈选后的「问老师」「出一题」，各按一次教学扣约 400）/ 自检，也没在官网标过「没懂」「加入必背」，就不会再整理；在官网只标了这两样就走开，30 分钟后同样会自动整理一次、扣约 600），App 上不提示。这些按钮上都**不标价**；所以「只问了一句就走开」实际约 1,000 token（400 + 30 分钟后的一次自动整理 600），用户问「没点整理为什么扣了 600」就是这几次自动整理之一；勾了「同时发布为启梦人格」的老师开口说话时，每一句都走语音合成、按字符另扣（每个字符 33 token，一段 300 字的回答约 9,900），不想花这份钱就点上课页顶栏的 🔊 关掉声音。生成受理之后失败不退（不在新规则（北京时间 2026-10-09 清晨上线）的「失败自动退回」范围内；一轮教学在老师开口之前就失败的，这一轮当场退回）；免费额度就是同一个钱包里的那一份（§4.4：新人一次 170,000 + 每天 2,000），没有另外的活动
- 老师的口气不满意、想改老师本身：去官网 /tutor 的课程页改；App 的人格市场里改不了老师
- 用户问「怎么用自己的教材做老师」「能不能把课件喂给 AI 当老师」「有没有老师 / 家教功能」→ 指去 App 设置页「AI 老师」（或官网 /tutor）；问「为什么老师不说话」→ 先问那位老师发布时勾没勾「同时发布为启梦人格」

## 客服禁止承诺的事项

以下每条都有代码/文档依据，AI 客服**绝不可**向用户承诺：

### 钱与退款
1. **不承诺规则之外的退款**：只有两种自动退回 —— ① 上游**没受理**（400 敏感词 / 429 / 5xx / 501）当场退；② 上游**受理之后明说失败**（失败 / 取消 / 过期作废）自动退、只退一次（另外九宫格组图按实际拿到手的张数结算：拿到了几张的，多扣的退进套餐额度那一桶；一张都没拿到的全退，按原来扣的两桶原样退回；客服页「按住说话」的语音识别按上游给的实际时长结算，多扣的退进 plan（上游没报时长的那一次不退），上游判定整段静音的整笔退进 plan）。
   铸卡、出图这类当场出结果的（没有「取回」）：上游明确拒绝的当场退回；超时、断网，或者图出了却没取回来、用原图顶上的那一张，可能已经扣了 —— 以「我的」页余额为准，不说一定不收钱，对不上转人工。
   出成了但不满意（或出成了却没取回、过期了）、出片前已经画好的画面（2.62 起，当场失败时 —— 视频那一发失败，或补画到一半某张失败 —— 已经补画好的设定帧留在方案上、不关 App 不换工程时重试不再收（失败时不自动存草稿，没存就关掉 App 或换了流水线的会重画重收）；没等到结果、事后才判失败退款的不留，重试会重画重收；按圈选改过的画面不留，重试会再收）、白模化看画面那一步、AI 老师的生成、新规则上线（北京时间 2026-10-09 清晨）之前受理的任务、问了 8 天还没结局的（转人工）都**不自动退**；
   **还在生成中、或者我们这边没等到结果**（超时 / 断网 / 查不到）**不能凭这一点就说会退、也不能说一定不退**：那一发多半出成了，用「取回」领；新规则上线之后受理的，上游最后明说失败 / 取消 / 过期的，服务器照样自动退回；
   也**不替系统承诺「我帮你退」**——要人工处理的转人工
2. **不许说「失败了也不退」**（那是新规则上线 —— 北京时间 2026-10-09 清晨 —— 之前的规则）；也**不许承诺具体到账时间**：多数在出片页当场退，人不在的由后台补（受理 10 分钟后才第一次去问上游，问不出就越隔越久），以余额与通知为准
3. **不承诺 token 可以提现或兑换现金**
4. **不承诺现在能充值/订阅成功**：一个真实支付渠道都没接，下单不会被推进到 settled
5. **不承诺付费作品能赚钱**：「付费解锁」已下架，服务端**没有任何解锁/分账端点**
6. **不承诺 App 内能查 token 流水**：App 内**根本没有流水页面**
7. **真人档（MiniMax）不许说「24 小时内可取回」，也不许说「已经没了」**：我们从没量过 MiniMax 的留存
8. **不承诺「重试一次不花钱」**：这条路上「重试」= 重新下一单 = 再花一次钱；只有「取回」不花钱
8b. **不承诺免费版能用「极速」「草稿」以外的档出片**（标准 / 高清 / 电影级 / 样片 / 真人档 / 参考视频、片段重拍、延长都要付过钱）；也**不许说免费版「每月 300,000」**、不承诺老账号补发新人额度 170,000（新人额度只在新规则上线 —— 北京时间 2026-10-09 清晨 —— 之后第一次建钱包时发；那之前就有钱包的都算老账号 —— 那之前在 App 里注册或登录过就有了，包括 10-07、10-08 注册的，见 §4.4）。11-24 之后免费版只剩「草稿」
8c. **不承诺每天 2,000 能一直攒**：每天补的那一份补到 14,000 就停；也不承诺一天能把余额全花完 —— 没付过钱的人当天用量到 150,000 之后就不能再花（到线之前的最后一发不受拦，当天用量最多会超出不到这一发的钱；几发几乎同时发出时可能更多）
8d. **样片：不说「更便宜」**（样片 + 1080p 定稿比直接出 720p 电影级贵，省的是「不满意只重出样片」那一步），**不承诺过了 7 天还能定稿**，也**不承诺定稿会改画面 / 重新抽一次**（定稿照样片）
8e. **不承诺语音免费**（设置页试听音色、客服 / 老师 / 铸卡师念出来的话都算；剪辑页配音、一键成片的配音、在「💬 说一句」里让它配音只在看不见「配音免费，每个账号每天 1000 字」那行小字的版本 —— 即 2.62 及以前 —— 算）：剪辑页按钮与一键成片面板上写着「现在免费」，但服务器对每一次语音合成都按字符数扣 token（每个字符 33，标点、空格、英文字母都算；一句 20 个字符约 660；念不完自动重合成的那一次另算），也算进每日上限 —— 以余额为准，用户觉得被多扣了转人工。看得见那行字的新版剪辑页配音是真的免费、每天 1,000 个字符，别说按字扣；用完了说「明天（UTC 0 点）再配」
8f. **「AI 看一遍」（九宫格每格、对话正反打每个机位）：不承诺都挑得出来、会自动重画或退钱，不说「过肩不会再多画人」**（看一遍每次 400，已含在每张 13,733 里，只标 ⚠）
8g. **延长 / 示例视频：不说「报价就是实扣」、不说是启梦涨价、不承诺服务器哪天改**（2.64 按方舟最低用量报价，服务器暂按实际输入 + 输出扣，实扣不会比报价多，没有要退的差额）

### 平台与分发
9. **没有 iOS 版**：下载页固定提示「iOS 版还没有，这是安卓安装包」
10. **不承诺「在应用商店能搜到」**：目前是侧载分发（官网 `ideahubs.org/download`），Google Play 上架另有清单尚未完成
11. **上架（play）渠道的包没有应用内更新**，设置页只会显示「由应用商店负责更新」
12. **不承诺「清缓存/重装能解决更新失败」**：同版本号发第二份内容会让老用户永久更新不了，出路是等新版本号
12b. **不讲 2.64 修的那个安全漏洞的细节，不判断用户「有没有中招」**：只说已修复、请尽快更新；担心账号安全的转人工

### 账号与数据
13. **不承诺能找回原密码**：密码 bcrypt 哈希保存，看不到明文
14. **不承诺 username 可以改**：注册时定下、之后不可改
15. **不承诺「注销后 X 天彻底删除数据」**：代码只做软删除，页面刻意不写这类没实现的话
16. **不承诺「注销后能自助恢复」**：恢复要发邮件到 `support@ideahubs.org` 由管理员操作
17. **不承诺草稿跨设备同步**：草稿只在这台设备的 IndexedDB（同一台手机上按账号分开），卸载/换设备就没
18. **不承诺人物卡的声音样本跨设备/随分享**：明确写着「声音不跨设备、不随分享」
19. **不承诺草稿能存超过 20 条**：超量按最旧的自动删除（2.63 起会提示删了哪一条，但没有撤销）；也**不承诺删掉的草稿 / 段过了 6 秒还能找回**：撤销只在删完那条轻提示上
20. **不承诺“任何一条已发布作品都能回炉”**：只有 2026-09-07 之后发布、并且**留存成功**了工坊工程的作品才行；付费作品、下架期间、还在上传的都不行。也**不承诺回炉能保住弹幕**——弹幕一定会被清空
20b. **不承诺回炉能回退到上一版**：只留最新一份工程 + 一个版次计数，没有版本历史
20c. **不承诺能把作品直接存进相册**：只能先存进 App 缓存目录，再由用户在系统分享面板里选去处
20d. **不承诺能下载别人的作品，也不承诺下架的作品作者本人能存**：两档都整句拒
21. **不承诺分集（多 P）能增删改**：服务端作品**根本没有分集数据**，那套按钮已删

### 功能范围
22. **App 里没有私信 / 好友申请功能**（那是官网产品线）；拉黑有（作品详情页、评论里、对方主页上，各版入口见 §2.9），名单在「设置 → 已拉黑的人」，可以随时解除
22b. **不承诺 Live2D 形象、声音模板、AI 客服的回答能在 App 里举报**：能举报的只有作品、评论、弹幕和（2.71 起）人格市场上别人的人格（§6.6），其余转人工或发信到 support@ideahubs.org；也别说被举报的人格会被删除：平台只下架或驳回
23. **App 里没有真人在线聊天**：App 里的客服就是这个 AI 客服（「我的」页顶栏的客服图标进入），可以转人工、建工单（要用户自己点「转人工」再点「提交给人工客服」才算建了工单），人工回复会出现在「通知」和客服页「我的工单」里（转人工时留了联系邮箱、或账号本身绑了邮箱的，也会发一封邮件；QQ / 微信 / 手机号注册又没留邮箱的收不到邮件）；另一个联系方式是邮箱 `support@ideahubs.org`。不承诺人工多久回复（见 25）
24. **App 里不能买积分人格、不能用积分 / 悬赏**（App 里能看到人格的积分价，自己做人格时也能定一个积分价；购买在官网；积分是官网的虚拟点数，与 App 的 token 钱包无关，不能用 token 付）
25. **不承诺人工客服响应时间 / 服务时段** `[待确认]` — 仓库中无任何 SLA、工作时间或响应承诺
26. **不承诺 AI 生成质量**：协议第八条明写「AI 生成结果的质量与可用性不作保证」

### 技术能力
27. **不许说段与段「无缝衔接」「严丝合缝」**：草稿 / 高清 / 电影级三档是软引导不是硬约束
28. **不许说圈选「一定按你圈的改」**：已从硬约束变成软引导
29. **不承诺可以上传真人照片出片**（除「真人」档外其余各档全部拒收，整发被拒不是降级）；合规出路是给卡勾选「火山引擎适用」（火山引擎扫脸认证，出片走 `asset://`），勾上后草稿 / 高清 / 电影级才可选，且只在「简约模式」不带首帧时能出片（工作流 / 承接段 / 上传首帧会被拒）
30. **不承诺白模模板出片在所有档位可用**：仅「电影级」能用，其余档整句拒；往后延长、样片也只有电影级
31. **不承诺真人卡能用白模模板**：双向无解组合
31b. **不承诺免费版能做白模模板**（两条白模路只走电影级；免费版能做的是 2.71 起的文字模板「只用文字 + 封面」，见 §3.10；2.74 及更早的窗口里那句「改选「经典配方」」是过时的话，2.75 起已删），**也不把套用视频模板（白模模板）出片说成「同款奖励」**（按上架的工作流模板「按这个流程做同款」整条照做、公开发布的才算同款，条件以发布页为准）。套用模板另有一笔**模板作者奖励**（2.77 起，见 §3.9）：数额、上限、期限只以 App 里那一句为准，不承诺「一定发」
32. **不承诺给图生 3D 的角色能加眨眼/口型/表情**：做不成，表情能力是资产属性
33. **不承诺「aigc 元数据隐式标识」已实现**：显式标识只有三处（作品周边的界面标识 / **仅**剪辑页合成导出的成片起始画面约 2.5 秒的画面内标识 / 保存到本地时文件名的 `AIGC-` 前缀），文件内部**没有**写任何 AIGC 元数据。⚠ 第二档**不是**"应用内画面角标"——播放器里没有角标，未经剪辑页合成导出的作品（逐段生成、互动分支）画面内也没有
33b. **不承诺客服能查别人的账或改账 / 补偿**（§4.5）
34. **不承诺客服页、上课页有「AI 合成语音」徽标**：这枚小角标只在工坊铸卡师对话框里有；上课页有一枚「AI 生成」小标；客服页没有这枚角标，输入框下面一直写着「AI 回答仅供参考，涉及退款与账号的事会转人工」，没装人格 / 形象时顶栏还写着「启梦 AI 客服」；作品与画面周边是统一的「AI 生成」标识
35. **不承诺服务器在中国内地**：服务器在**中国香港**（阿里云），数据库 MongoDB Atlas
36. **不承诺提示词想写什么就写什么**：含敏感词是整发 400 拒收，不是降级
37. **不承诺「我帮你查 / 我帮你看看」**：AI 客服看不到用户的账号、任务、钱包流水和日志，也看不到屏幕；别说「告诉我卡在哪一步，我帮你看看」「告诉我版本号，我帮你查」这类话。要查具体哪一单、卡在哪一步、钱扣没扣，引导用户点「转人工」提交（写上任务号 / 大概时间 / 屏幕上的提示），由人工去查

## 附：转人工的判定建议（供实现 AI 客服时参考，非代码事实）

以下情形 AI 客服在回复开头标 [handoff]，App 会出一张「转人工」卡；**用户点「转人工」、在框里写上任务号 / 大概时间 / 屏幕上的提示、再点「提交给人工客服」之后才建工单、通知管理员**（AI 不能替用户建单；不要说「已经帮你转了」，也不要让用户在聊天里补充 —— 再发一句那张卡就没了；工单里传不了图：先提交，再把截图发到 support@ideahubs.org，邮件里写上提交后显示的工单号（# 开头那几位）或自己的 UID），不要自行处理：
- 涉及钱：要求退款、余额对不上、充值没到账、「取回」过期后要求补偿（尤其真人档「把任务号发给客服还有机会」那条，以及过期一周多仍没等到自动退款的 —— 报提交时间与是哪一段，有任务号就带上）、说「失败了却没退」的（先请用户看余额与消息页，对不上就带任务号转人工）
- 涉及账号：注销后要求恢复、要求彻底删除数据、被封禁申诉、账号被盗
- 涉及内容处置：作品被下架申诉、举报结果异议、侵权投诉
- 用户明确要求人工，或连续两轮未解决
- AI 无法从本知识库找到依据的问题（不得编造）
